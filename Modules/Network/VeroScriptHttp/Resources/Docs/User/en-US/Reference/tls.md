# HTTP — TLS

Use `Http::FServerOptions::Tls` or script `listen_tls` for an HTTPS server. The [Network TLS](../../../../../../VeroScriptNetwork/Resources/Docs/User/en-US/Reference/tls.md) defines shared TLS options and the separation between transport TLS and curl HTTPS.
