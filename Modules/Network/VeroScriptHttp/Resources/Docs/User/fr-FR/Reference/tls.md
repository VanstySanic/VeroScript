# HTTP — TLS

Utilisez `Http::FServerOptions::Tls` ou `listen_tls` en script pour un serveur HTTPS. Le [Network TLS](../../../../../../VeroScriptNetwork/Resources/Docs/User/fr-FR/Reference/tls.md) définit les options TLS communes et la séparation entre le TLS du transport et HTTPS de curl.
