# HTTP — TLS

HTTPS 서버에는 `Http::FServerOptions::Tls` 또는 스크립트 `listen_tls`를 사용하세요. 공통 TLS 옵션과 전송 TLS/curl HTTPS의 구분은 [Network TLS](../../../../../../VeroScriptNetwork/Resources/Docs/User/ko-KR/Reference/tls.md)을 참조하세요.
