# HTTP: 소스 구성

Http는 요청/응답 및 클라이언트/서버 퍼사드 계약, 프로토콜 바인딩과 패키지 설정을 관리합니다. `Internal/` 훅은 Curl 클라이언트와 Boost 서버를 연결하며 공통 전송 계약은 Network에 속합니다.

공통 컨텍스트/작업 소유권, 레지스트리 구성, SDK 경계와 빌드 옵션은 [Network](../../../../../VeroScriptNetwork/Resources/Docs/Developer/ko-KR/index.md)에서 관리합니다.
