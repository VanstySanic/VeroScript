# WebSocket: ソースの所属

WebSocket は接続、メッセージ、プロトコルバインディングの契約とパッケージ設定を管理します。`Internal/` フックは Boost 実装に接続し、共通のトランスポート契約は Network に属します。

共通のコンテキストと操作の所有権、レジストリ合成、SDK 境界、ビルド設定は [Network](../../../../../VeroScriptNetwork/Resources/Docs/Developer/ja-JP/index.md) で管理します。
