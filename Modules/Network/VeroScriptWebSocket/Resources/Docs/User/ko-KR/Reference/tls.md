# WebSocket — TLS

용도에 따라 `wss` URL, `WebSocket::FOptions::Tls` 또는 스크립트 `connect_tls` / `listen_tls`를 사용하세요. 공통 TLS 옵션과 공급자 가용성은 [Network TLS](../../../../../../VeroScriptNetwork/Resources/Docs/User/ko-KR/Reference/tls.md)을 참조하세요.
