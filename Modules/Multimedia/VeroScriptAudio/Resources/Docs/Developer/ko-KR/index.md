# 유지보수: VeroScriptAudio

이 모듈은 오디오 장치, PCM/WAVE 및 스크립트 바인딩 계약을 관리합니다. 공개 인터페이스는 [`Public/VeroScriptAudio.h`](../../../../Public/VeroScriptAudio.h)에, 모듈별 입력은 [`Resources/Tests`](../../../Tests)에 있습니다.

공통 공급자 경계, 재빌드 요구 사항, 검증 및 법적 리소스 관리는 [멀티미디어 유지보수](../../../../../../../Resources/Docs/Developer/ko-KR/multimedia.md)에서 설명합니다.

`VEROSCRIPT_BUILD_AUDIO` · `VEROSCRIPT_SDL3_AUDIO` · `VEROSCRIPT_VISUAL_SCRIPT_BINDINGS`
