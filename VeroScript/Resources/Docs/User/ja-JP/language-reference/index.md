- [型変換](type-conversions.md): 数値、テキスト、構造体、クラス、インターフェイス値の変換境界。
- [オーバーロード解決](overload-resolution.md): 候補、引数の一致、参照マーカー、および曖昧さ。
- [診断とエラー](diagnostics.md): コンパイル診断、実行時エラー、言語選択、およびチェック。
- [バージョン管理と互換性](versioning.md): 言語バージョン、バイトコード、パッケージ、およびホスト バインディング境界。
