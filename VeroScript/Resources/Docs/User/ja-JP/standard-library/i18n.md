# アプリケーションの国際化 — std::i18n

i18n.vs または core.vs をインポートします。アプリケーションのコンテキストはプロセス診断言語から独立しています。コアは型付き名前置換を提供し、ICU とファイルリソースの読み込みは外部プロバイダーで追加します。

```VeroScript
import "i18n.vs";
void main()
{
	std::i18n::arguments args = std::i18n::arguments();
	args.set("count", std::i18n::argument(18446744073709551615u64));
	std::i18n::context app = std::i18n::context();
	assert(app.format("{count} items", args) == "18446744073709551615 items");
	assert(app.resolve(std::i18n::text("{literal}")) == "{literal}");
}
```

## 型と操作

コピーは元の型を保持します。arguments.set/get/contains/remove/clear/size/names は所有する名前付き引数を管理し、string、bool、各幅の整数、float、double を保持します。

## 設定、スナップショット、プロバイダー

代入は同じ context を共有します。clone() は独立した識別子と設定を作り、configuration() はコピーを返します。language、fallback_languages、format_locale、format_options は変更可能です。空の format_locale は言語に追従します。

snapshot は設定とプロバイダーを固定します。version は ==/!= で比較するプロセス内の不透明な値です。後の更新は既存のスナップショットに影響しません。

## 書式とエラー

format(pattern,args) は vero.named の {name}、{{、}} を使用し、文字列を再解釈しません。名前はドットとハイフンを許す ASCII 識別子です。整数は正確に出力され、不正確な変換と非有限値の出力は拒否されます。

text("literal") は波括弧を含めてそのまま解決されます。text::message_key(domain,key) は引数なしの参照、text::message(domain,key,args) は引数のスナップショットを保存します。resolve は文字列、resolve_versioned は一致言語とバージョンも返します。

snapshot.lookup(domain,key) は pattern()、format_id()、matched_language()、version() を持つ message_template を返します。外部文法は format_with(pattern,args,format_id) を使用します。std.format テンプレートは明示的に std::format に渡せます。文法の自動変換はありません。

不足するリソースや引数、無効な状態、未対応のオプションや文法、プロバイダーの失敗は通常のスクリプトエラーです。プロバイダーなしでもリテラルと名前付き書式は使えます。text はコンテナー値、関数の値、`std::attribute<text>` に利用できますが、map/set のキーには使えません。

## 言語タグと明示的なフォールバック

`std::i18n::normalize_language_tag(tag)` は BCP 47 構文と大文字小文字を正規化します。`zh-hant-tw` は `zh-Hant-TW` になり、言語のみの `en` も有効です。サブタグはハイフンで区切ります。`ja_JP.UTF-8`、前後の空白、`C` は拒否します。`POSIX` は構文上 `posix` として受理しますが、`en-US` には変換しません。診断言語の選択とは異なる規則です。

新しい `configuration` の既定値は言語 `en-US`、空の `fallback_languages` 配列、空の `format_locale`、空の `format_options` です。リソース検索は構成した言語の完全一致、次に明示したフォールバックを順番に試します。親タグ、別地域、英語を自動追加しません。メッセージが見つからない場合だけ次へ進み、プロバイダーの失敗では解決を中止します。英語へのフォールバックが必要なら `en-US` を指定してください。空の `format_locale` は要求したコンテキスト言語に従い、メッセージが見つかったフォールバック言語には切り替わりません。

`vero.named` はカルチャー固有の数値、通貨、複数形の規則を適用せず、空でない `format_options` を拒否します。それらの規則やカスタム引数値には、明示的にインストールした拡張フォーマッターとその形式 ID を使用してください。

```VeroScript
import "i18n.vs";

void main()
{
	assert(std::i18n::normalize_language_tag("zh-hant-tw") == "zh-Hant-TW");
	std::i18n::configuration config = std::i18n::configuration();
	config.language = "fr-FR";
	array<string> fallbacks = {"en-US"};
	config.fallback_languages = fallbacks;
	std::i18n::context app = std::i18n::context(config);
	assert(app.configuration().language == "fr-FR");
}
```
