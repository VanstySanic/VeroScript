# Application internationalization — std::i18n

Import `i18n.vs` or `core.vs`. Application contexts are independent from the process diagnostic language. Core supports typed named substitution; ICU grammars and file resource loaders are separate providers.

```VeroScript
import "i18n.vs";
void main()
{
	std::i18n::arguments args = std::i18n::arguments();
	args.set("count", std::i18n::argument(18446744073709551615u64));
	std::i18n::context app = std::i18n::context();
	assert(app.format("{count} items", args) == "18446744073709551615 items");
	assert(app.resolve(std::i18n::text("{literal}")) == "{literal}");
}
```

## Types and operations

Value copies preserve original argument kinds. `arguments.set/get/contains/remove/clear/size/names` manage a copied, owned parameter set. Values retain string, bool, all integer widths, float and double.

## Configuration, snapshots and providers

Assignment shares a context; `clone()` creates an independent identity and configuration. `configuration()` returns a value copy. `language`, `fallback_languages`, `format_locale` and `format_options` are writable configuration properties. Empty `format_locale` follows the language.

A snapshot fixes configuration and provider views. Compare `version` with `==`/`!=`; its revisions are opaque and valid only in this process. A later provider publication or configuration change does not alter an existing snapshot.

## Formatting and errors

`format(pattern,args)` uses `vero.named`: `{name}`, `{{`, `}}`; strings are inserted once. Names in this grammar are ASCII identifiers with dots/hyphens. Integers render exactly; numeric accessors reject inexact conversions. Non-finite numeric output is rejected.

`text("literal")` resolves verbatim, including braces. `text::message_key(domain,key)` saves a resource reference without parameters; `text::message(domain,key,args)` freezes parameters. `resolve` returns string; `resolve_versioned` includes matched language and version.

`snapshot.lookup(domain,key)` returns `message_template` with `pattern()`, `format_id()`, `matched_language()` and `version()`. Use `format_with(pattern,args,format_id)` for an extension grammar. A `std.format` template can be passed explicitly to `std::format`; no automatic grammar conversion occurs.

Missing resources, missing parameters, invalid state, unsupported options/grammar and failed providers raise normal script errors. A context without providers still supports literal text and named formatting. `text` works as a container value, function value and `std::attribute<text>` payload; it is not a map/set key.

## Language tags and explicit fallback

`std::i18n::normalize_language_tag(tag)` validates BCP 47 syntax and normalizes casing: `zh-hant-tw` becomes `zh-Hant-TW`, and a language-only tag such as `en` is valid. Separate subtags with hyphens. OS spellings such as `ja_JP.UTF-8`, surrounding whitespace and `C` are rejected. `POSIX` is accepted syntactically as `posix`; it is not mapped to `en-US`. This differs from diagnostic language selection.

A new `configuration` uses `en-US`, an empty `fallback_languages` array, an empty `format_locale` and empty `format_options`. Resource lookup asks for the configured language exactly, then each explicitly configured fallback in order. It does not add parent tags, another region or English automatically. Only a missing message continues to the next language; provider failures stop resolution. Configure `en-US` as a fallback if your application requires an English baseline. The formatting locale follows the requested context language when empty, even if a resource was found in a fallback language.

`vero.named` formats scalars without culture-specific number, currency or plural rules and rejects nonempty `format_options`. Use an explicitly installed formatter and its format ID for such rules. Custom argument values also require an extension formatter.

```VeroScript
import "i18n.vs";

void main()
{
	assert(std::i18n::normalize_language_tag("zh-hant-tw") == "zh-Hant-TW");
	std::i18n::configuration config = std::i18n::configuration();
	config.language = "fr-FR";
	array<string> fallbacks = {"en-US"};
	config.fallback_languages = fallbacks;
	std::i18n::context app = std::i18n::context(config);
	assert(app.configuration().language == "fr-FR");
}
```
