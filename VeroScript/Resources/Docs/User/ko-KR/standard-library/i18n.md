# 응용 프로그램 국제화 — std::i18n

i18n.vs 또는 core.vs를 가져옵니다. 응용 프로그램 컨텍스트는 프로세스 진단 언어와 독립적입니다. 핵심은 형식이 보존되는 이름 치환을 제공하며 ICU 및 파일 리소스 로더는 별도 공급자로 연결합니다.

```VeroScript
import "i18n.vs";
void main()
{
	std::i18n::arguments args = std::i18n::arguments();
	args.set("count", std::i18n::argument(18446744073709551615u64));
	std::i18n::context app = std::i18n::context();
	assert(app.format("{count} items", args) == "18446744073709551615 items");
	assert(app.resolve(std::i18n::text("{literal}")) == "{literal}");
}
```

## 형식과 작업

복사는 원래 형식을 유지합니다. arguments.set/get/contains/remove/clear/size/names는 소유한 이름 있는 인수를 관리하며 string, bool, 모든 정수 폭, float, double을 보존합니다.

## 설정, 스냅샷 및 공급자

대입은 같은 context를 공유하고 clone()은 독립 식별자와 설정을 만듭니다. configuration()은 복사본을 반환합니다. language, fallback_languages, format_locale, format_options를 변경할 수 있으며 빈 format_locale은 언어를 따릅니다.

snapshot은 설정과 공급자를 고정합니다. version은 ==/!=로 비교하는 프로세스 내부의 불투명 값입니다. 이후 업데이트는 기존 스냅샷을 변경하지 않습니다.

## 서식과 오류

format(pattern,args)는 vero.named의 {name}, {{, }}를 사용하며 문자열을 재해석하지 않습니다. 이름은 점과 하이픈을 허용하는 ASCII 식별자입니다. 정수를 정확히 출력하고 부정확한 변환 및 유한하지 않은 값의 출력을 거부합니다.

text("literal")은 중괄호를 그대로 보존합니다. text::message_key(domain,key)는 인수 없는 참조를, text::message(domain,key,args)는 인수 스냅샷을 저장합니다. resolve는 문자열을, resolve_versioned는 일치 언어와 버전도 반환합니다.

snapshot.lookup(domain,key)는 pattern(), format_id(), matched_language(), version()을 제공하는 message_template을 반환합니다. 확장 문법은 format_with(pattern,args,format_id)를 사용합니다. std.format 템플릿은 명시적으로 std::format에 전달할 수 있으며 자동 문법 변환은 없습니다.

리소스나 인수 누락, 잘못된 상태, 지원하지 않는 옵션/문법, 공급자 실패는 일반 스크립트 오류입니다. 공급자 없이도 리터럴과 이름 서식을 사용할 수 있습니다. text는 컨테이너 값, 함수 값 및 `std::attribute<text>`에 사용할 수 있지만 map/set 키는 아닙니다.

## 언어 태그와 명시적 대체 언어

`std::i18n::normalize_language_tag(tag)`는 BCP 47 구문을 검사하고 대소문자를 정규화합니다. `zh-hant-tw`는 `zh-Hant-TW`가 되며 언어만 있는 `en`도 유효합니다. 하위 태그는 하이픈으로 구분합니다. `ja_JP.UTF-8`, 앞뒤 공백, `C`는 거부합니다. `POSIX`는 구문상 `posix`로 허용하지만 `en-US`로 변환하지 않습니다. 진단 언어 선택과는 다른 규칙입니다.

새 `configuration`의 기본값은 `en-US`, 빈 `fallback_languages` 배열, 빈 `format_locale`, 빈 `format_options`입니다. 리소스 조회는 구성한 언어의 정확한 일치를 시도한 뒤 명시한 대체 언어를 순서대로 시도합니다. 부모 태그, 다른 지역, 영어를 자동으로 추가하지 않습니다. 메시지가 없는 경우에만 다음 언어로 진행하며 공급자 실패는 해결을 중단합니다. 영어 기준 언어가 필요하면 `en-US`를 직접 추가하세요. 빈 `format_locale`은 요청한 컨텍스트 언어를 따르며 메시지가 발견된 대체 언어로 바뀌지 않습니다.

`vero.named`는 문화권별 숫자, 통화, 복수형 규칙을 적용하지 않고 비어 있지 않은 `format_options`를 거부합니다. 이러한 규칙과 사용자 지정 인수 값에는 명시적으로 설치한 확장 포매터와 해당 형식 ID를 사용하세요.

```VeroScript
import "i18n.vs";

void main()
{
	assert(std::i18n::normalize_language_tag("zh-hant-tw") == "zh-Hant-TW");
	std::i18n::configuration config = std::i18n::configuration();
	config.language = "fr-FR";
	array<string> fallbacks = {"en-US"};
	config.fallback_languages = fallbacks;
	std::i18n::context app = std::i18n::context(config);
	assert(app.configuration().language == "fr-FR");
}
```
