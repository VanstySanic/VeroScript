# 언어 참고자료

이 섹션에서는 교차 언어 규칙을 수집합니다. 개별 구문 항목은 [언어 기본 사항](../language-basics/index.md)을, 라이브러리 API는 [표준 라이브러리 참조](../standard-library/index.md)를 참조하세요.

- [유형 변환](type-conversions.md): 숫자, 텍스트, 구조체, 클래스 및 인터페이스 값에 대한 변환 경계입니다.
- [오버로드 해결](overload-resolution.md): 후보, 인수 일치, 참조 표시 및 모호성.
- [진단 및 오류](diagnostics.md): 진단, 런타임 오류, 언어 선택 및 확인을 컴파일합니다.
- [버전 관리 및 호환성](versioning.md): 언어 버전, 바이트코드, 패키지 및 호스트 바인딩 경계.

- [constexpr](constexpr.md)
