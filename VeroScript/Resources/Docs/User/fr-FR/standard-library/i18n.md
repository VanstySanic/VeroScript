# Internationalisation des applications — std::i18n

Importez `i18n.vs` ou `core.vs`. Les contextes applicatifs sont indépendants de la langue des diagnostics du processus. Le cœur fournit la substitution nommée typée ; ICU et les chargeurs de fichiers sont des fournisseurs séparés.

```VeroScript
import "i18n.vs";
void main()
{
	std::i18n::arguments args = std::i18n::arguments();
	args.set("count", std::i18n::argument(18446744073709551615u64));
	std::i18n::context app = std::i18n::context();
	assert(app.format("{count} items", args) == "18446744073709551615 items");
	assert(app.resolve(std::i18n::text("{literal}")) == "{literal}");
}
```

## Types et opérations

Les copies conservent les types originaux. arguments.set/get/contains/remove/clear/size/names gèrent les paramètres possédés : string, bool, entiers de toutes les largeurs, float et double.

## Configuration, instantanés et fournisseurs

Une affectation partage le context ; clone() crée une identité et une configuration indépendantes. configuration() renvoie une copie. language, fallback_languages, format_locale et format_options sont modifiables ; un format_locale vide suit la langue.

Un snapshot fixe la configuration et les fournisseurs. Comparez version avec ==/!= ; les révisions sont opaques et locales au processus. Une publication ou modification ultérieure ne change pas les instantanés existants.

## Formatage et erreurs

format(pattern,args) utilise vero.named : {name}, {{ et }}. Une chaîne est insérée une seule fois. Les noms sont des identifiants ASCII pouvant contenir points et tirets. Les entiers restent exacts ; les conversions inexactes et le rendu des valeurs non finies sont rejetés.

text("literal") conserve les accolades. text::message_key(domain,key) crée une référence sans paramètres ; text::message(domain,key,args) fige les paramètres. resolve renvoie une chaîne ; resolve_versioned conserve la langue trouvée et la version.

snapshot.lookup(domain,key) renvoie un message_template avec pattern(), format_id(), matched_language() et version(). Utilisez format_with(pattern,args,format_id) pour une grammaire externe. Un modèle std.format peut être passé explicitement à std::format, sans conversion automatique.

Ressources ou paramètres manquants, état invalide, options/grammaires non prises en charge et fournisseurs défaillants produisent des erreurs ordinaires. Sans fournisseur, les textes littéraux et le formatage nommé restent disponibles. text est utilisable comme valeur de conteneur, valeur de fonction et contenu de `std::attribute<text>`, mais pas comme clé map/set.

## Langues et repli explicite

`std::i18n::normalize_language_tag(tag)` vérifie la syntaxe BCP 47 et normalise la casse : `zh-hant-tw` devient `zh-Hant-TW`, et une langue seule comme `en` est valide. Séparez les sous-balises par des tirets. `ja_JP.UTF-8`, les espaces autour de la balise et `C` sont rejetés. `POSIX` est accepté syntaxiquement comme `posix`, sans être converti en `en-US`. Cette règle diffère de la sélection des diagnostics.

Une nouvelle `configuration` utilise `en-US`, un tableau `fallback_languages` vide, un `format_locale` vide et des `format_options` vides. La recherche demande exactement la langue configurée, puis les replis explicites dans l’ordre. Aucun parent, autre région ou repli anglais n’est ajouté automatiquement. Seule l’absence du message permet de continuer ; un échec du fournisseur interrompt la résolution. Ajoutez `en-US` aux replis si votre application exige une référence anglaise. Un `format_locale` vide suit la langue demandée du contexte, même lorsque le message provient d’un repli.

`vero.named` formate les scalaires sans règles culturelles de nombres, monnaies ou pluriels et rejette des `format_options` non vides. Pour ces règles, installez explicitement un fournisseur de formatage et utilisez son identifiant. Les valeurs d’argument personnalisées exigent également ce type de fournisseur.

```VeroScript
import "i18n.vs";

void main()
{
	assert(std::i18n::normalize_language_tag("zh-hant-tw") == "zh-Hant-TW");
	std::i18n::configuration config = std::i18n::configuration();
	config.language = "fr-FR";
	array<string> fallbacks = {"en-US"};
	config.fallback_languages = fallbacks;
	std::i18n::context app = std::i18n::context(config);
	assert(app.configuration().language == "fr-FR");
}
```
