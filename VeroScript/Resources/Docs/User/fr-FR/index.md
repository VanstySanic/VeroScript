Les fragments courts illustrent une opération : placez les instructions exécutables dans une fonction et ajoutez les déclarations ou imports présentés dans le texte qui les accompagne. Un fragment utilisant une variable ou un type défini auparavant ne suffit pas à lui seul dans un fichier vide.
