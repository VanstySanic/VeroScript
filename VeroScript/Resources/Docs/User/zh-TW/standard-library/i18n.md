# 應用程式國際化 — std::i18n

匯入 `i18n.vs` 或 `core.vs`。應用程式上下文獨立於程序診斷語言。核心提供具型別的具名替換；ICU 格式語法及檔案資源載入由獨立提供者接入。

```VeroScript
import "i18n.vs";
void main()
{
	std::i18n::arguments args = std::i18n::arguments();
	args.set("count", std::i18n::argument(18446744073709551615u64));
	std::i18n::context app = std::i18n::context();
	assert(app.format("{count} items", args) == "18446744073709551615 items");
	assert(app.resolve(std::i18n::text("{literal}")) == "{literal}");
}
```

## 型別與操作

參數複製保留原始類別。arguments.set/get/contains/remove/clear/size/names 管理具有值語意的具名參數，保留 string、bool、各寬度整數、float 和 double。

## 設定、快照與提供者

賦值共用同一 context；clone() 建立獨立身分及設定。configuration() 傳回設定副本。language、fallback_languages、format_locale、format_options 可讀寫；空 format_locale 表示跟隨語言。

snapshot 固定設定及提供者視圖。version 僅以 ==／!= 判斷變更，修訂號是目前程序內的不透明標記。新資源或設定不會改變既有快照。

## 格式化與錯誤

format(pattern,args) 使用 vero.named：{name}、{{、}}，字串只插入一次。名稱使用可含點與連字號的 ASCII 識別符。整數不失精度；數值讀取拒絕不精確轉換，基礎格式器拒絕非有限數值。

text("literal") 原樣解析並保留大括號。text::message_key(domain,key) 儲存無參數資源參照；text::message(domain,key,args) 凍結參數。resolve 傳回 string；resolve_versioned 保留匹配語言及版本。

snapshot.lookup(domain,key) 傳回具有 pattern()、format_id()、matched_language()、version() 的 message_template。擴充語法使用 format_with(pattern,args,format_id)。std.format 範本可明確交給 std::format，不會自動轉換語法。

資源或參數缺漏、無效狀態、未支援的選項或語法以及提供者失敗均使用一般腳本錯誤。無提供者仍能解析文字與具名格式。text 可作容器值、函式值及 `std::attribute<text>` 內容，不作 map/set 鍵。

## 語言標籤與明確回退

`std::i18n::normalize_language_tag(tag)` 驗證 BCP 47 語法並正規化大小寫：`zh-hant-tw` 變為 `zh-Hant-TW`，僅含語言的 `en` 也有效。子標籤之間使用連字號。`ja_JP.UTF-8`、前後空白與 `C` 會被拒絕；`POSIX` 在語法上被接受並變為 `posix`，不會對應至 `en-US`。它與診斷語言選擇採用不同規則。

新的 `configuration` 預設使用 `en-US`、空的 `fallback_languages` 陣列、空的 `format_locale` 與空的 `format_options`。資源查詢先精確要求設定的語言，再依序要求明確設定的回退語言，不自動加入父標籤、其他地區或英語。僅訊息不存在時繼續回退；提供者失敗會終止解析。應用程式需要英語基準時，應明確加入 `en-US`。空的 `format_locale` 跟隨內容要求的語言，即使資源最後來自回退語言，也不會自動切換。

`vero.named` 不套用特定文化的數字、貨幣或複數規則，並拒絕非空的 `format_options`。需要這些規則或自訂參數值時，應明確安裝擴充格式化器並使用其格式 ID。

```VeroScript
import "i18n.vs";

void main()
{
	assert(std::i18n::normalize_language_tag("zh-hant-tw") == "zh-Hant-TW");
	std::i18n::configuration config = std::i18n::configuration();
	config.language = "fr-FR";
	array<string> fallbacks = {"en-US"};
	config.fallback_languages = fallbacks;
	std::i18n::context app = std::i18n::context(config);
	assert(app.configuration().language == "fr-FR");
}
```
