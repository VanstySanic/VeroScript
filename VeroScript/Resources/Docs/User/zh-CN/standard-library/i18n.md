# 应用国际化 — std::i18n

导入 `i18n.vs` 或 `core.vs`。应用上下文独立于进程诊断语言。核心提供带类型的命名替换；ICU 格式语法及文件资源加载由独立提供者接入。

```VeroScript
import "i18n.vs";
void main()
{
	std::i18n::arguments args = std::i18n::arguments();
	args.set("count", std::i18n::argument(18446744073709551615u64));
	std::i18n::context app = std::i18n::context();
	assert(app.format("{count} items", args) == "18446744073709551615 items");
	assert(app.resolve(std::i18n::text("{literal}")) == "{literal}");
}
```

## 类型与操作

参数复制保留原始类别。`arguments.set/get/contains/remove/clear/size/names` 管理具有值语义的命名参数，保留 string、bool、各宽度整数、float 和 double。

## 配置、快照与提供者

赋值共享同一 context；`clone()` 创建独立身份及配置。`configuration()` 返回配置副本。配置属性 `language`、`fallback_languages`、`format_locale`、`format_options` 可读写；空 `format_locale` 表示跟随语言。

snapshot 固定配置和提供者视图。version 只通过 `==`／`!=` 判断变化，修订号是当前进程内的不透明标记。发布新资源或修改上下文不会改变已取得的快照。

## 格式化与错误

`format(pattern,args)` 使用 `vero.named`：`{name}`、`{{`、`}}`，字符串只插入一次。此语法的名称采用可含点及连字符的 ASCII 标识符。整数输出不丢失精度；数值读取拒绝不精确转换，基础格式器拒绝非有限数值。

`text("literal")` 原样解析，保留花括号。`text::message_key(domain,key)` 保存无参数资源引用；`text::message(domain,key,args)` 冻结参数。resolve 返回 string；resolve_versioned 保留匹配语言和版本。

`snapshot.lookup(domain,key)` 返回具有 pattern()、format_id()、matched_language()、version() 的 message_template。扩展语法使用 format_with(pattern,args,format_id)。std.format 模板可以显式交给 std::format，不会自动转换格式语法。

缺少资源、缺少参数、状态无效、不支持选项或语法、提供者失败均走普通脚本错误路径。无提供者时仍可解析普通文字及命名格式化。text 可作容器值、函数值及 `std::attribute<text>` 载荷，不作为 map/set 键。

## 语言标签与显式回退

`std::i18n::normalize_language_tag(tag)` 校验 BCP 47 语法并规范大小写：`zh-hant-tw` 变为 `zh-Hant-TW`，仅含语言的 `en` 也有效。子标签之间使用连字符。`ja_JP.UTF-8`、首尾空白和 `C` 会被拒绝；`POSIX` 在语法上被接受并变为 `posix`，不会映射成 `en-US`。它与诊断语言选择采用不同的规则。

新 `configuration` 默认使用 `en-US`、空的 `fallback_languages` 数组、空 `format_locale` 和空 `format_options`。资源查找先精确请求配置的语言，再按顺序请求显式配置的回退语言，不自动追加父标签、其他地区或英语。仅消息不存在时继续回退；提供者失败会终止解析。应用需要英语基线时，应显式加入 `en-US`。空 `format_locale` 跟随上下文请求的语言，即使资源最终来自回退语言，也不会自动切换。

`vero.named` 不应用特定文化的数字、货币或复数规则，并拒绝非空 `format_options`。需要这些规则或自定义参数值时，应显式安装扩展格式化器并使用其格式 ID。

```VeroScript
import "i18n.vs";

void main()
{
	assert(std::i18n::normalize_language_tag("zh-hant-tw") == "zh-Hant-TW");
	std::i18n::configuration config = std::i18n::configuration();
	config.language = "fr-FR";
	array<string> fallbacks = {"en-US"};
	config.fallback_languages = fallbacks;
	std::i18n::context app = std::i18n::context(config);
	assert(app.configuration().language == "fr-FR");
}
```
