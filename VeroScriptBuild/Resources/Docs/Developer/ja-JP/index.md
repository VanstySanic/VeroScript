# Build サービスの保守

## 計画と実行

`FBuilder::Plan` はプロセッサー、ファクトリー、子プロセスを実行せず、グラフ、ソース／成果物識別、プロバイダー、ランチャーテンプレートを凍結します。`FBuildRequest` の境界パスは絶対パスで、設定内パスは選択したプロジェクトルートから解決し、プロセスのディレクトリーを変更しません。`FServices` はカタログ、コールバック、明示的なツールチェーン／環境識別を保持します。プロバイダーの `Plan` に実行副作用を入れません。

`FBuilder::Execute` は凍結入力を再検証し、変更時は新しい計画を要求します。追加入力は既存ダイジェストを置換せず `FStepContext::TrackInput` で報告します。成果物参照は宣言された入力フィールドだけで解釈し、プロバイダーの `options` は不透明な JSON のままにします。キャッシュ識別は設定、上流内容、プロバイダー識別、出力ハッシュを含みます。カスタムキャッシュには決定性とツールチェーン識別の明示が必要です。動的プロセッサーや暗号／信頼に依存するコンパイルは保守的に再実行します。

## 公開とターゲット方針

ターゲットごとに同一ボリューム上で所有記録とともにアトミックに公開します。他者の出力や変更済み出力は上書きしません。後続ターゲットの失敗で独立した公開済みターゲットを戻しません。利用中は成果物所有者と配置リースを保持します。`Deploy` と `LeaseDeployment` はインストール済み凍結環境を使い、インストールにフォールバックしません。

アプリ内容はビルドホストではなく選択ターゲットのプラットフォーム／ABI で検証します。実際のネイティブ実行は対象環境で別途検証が必要です。ソースアプリは移植可能な既定値と runtime+compile 用途を保持し、開発専用検索パスを拒否します。ランタイムとブートストラップは明示的な検証済み入力で、テンプレート変更は計画／キャッシュを無効化します。ネイティブラッパーとプラットフォーム署名は内容組み立てと分けます。

プロセスにはシェルを介さず実行ファイルと引数配列を渡します。制限付きスクリプトは宣言済み入出力ヘルパーと制限を使い、信頼するネイティブプロバイダー／プロセスは OS サンドボックスではありません。リソース変換前に既存署名を検証します。再暗号化では既存エンベロープを一度復号し、署名内容を変更する場合は新方針を要求します。変更しないコピーは署名を保持します。検証失敗時は公開せず、秘密鍵を設定や成果物に保存しません。

## 統合と検証

`Public/VeroScriptBuild.h`、計画／実行、`Resources/Schemas/veroscript-build.schema.json`、CLI、Application／パッケージアダプターを一致させます。ルートビルドは `VeroScriptBuildTests` を有効化し、`Resources/Examples/hello` と `Resources/Examples/generated` は各出力と生成処理を示します。古い計画、キャッシュ無効化、所有リース、ターゲット選択、署名失敗、アトミック公開を確認してください。CLI 手順と実行例はユーザーガイドに置き、プラットフォーム実行と署名は別途検証を記録します。
