# 工具链测试与扩展规则

本文档记录扩展工具链层时必须遵守的兼容性规则。

## 功能与协议覆盖

每项公共功能都需要结果级测试；跨越 LSP/DAP 边界的功能还需要序列化和传输覆盖。LSP 测试应覆盖帧、JSON-RPC 关联、格式错误输入、初始化、生命周期通知、增量同步、文档版本、取消、诊断、配置、完成、悬停、导航、符号、语义令牌、签名帮助、引用、高亮、重命名、格式化、工作区符号、关闭和退出，以及不支持方法的错误。补全覆盖还应验证文本匹配排序、`sortText` 和保守的 `preselect` 规则；语义令牌覆盖应验证词法回退范围、不完整缓冲区恢复、基元类型词为 `keyword`、容器类型词为 `type`。内置类型测试还应覆盖本地化悬停、无源定义和拒绝重命名。

限定命名空间补全的覆盖还必须证明：叶子名称 `Label` 与 `InsertText` 仍是插入契约，`LabelDescription` 会序列化为 `labelDetails.description`，可选的 `$valencePresentation` 具有正确的 UTF-16 展示片段且不改变过滤或排序。

命名空间段补全测试还要分别验证：表达式／语句中的补全仅在替换范围后面没有分隔符时追加 `::`；补全
`using namespace` 目标时只插入叶子名称。

工作区测试应覆盖覆盖层、导入文件分析、导入路径、定义/预定义宏、循环导入、项目范围访问、有序绑定目录、重复定义、目录重载和陈旧诊断清除。本地化测试验证目录键/占位符一致性、回退、稳定诊断标识符、内置类型显示文本的本地化以及不可翻译的协议和语言标识符。测试必须在运行时发现目录，不得假定固定区域数。

## 扩展边界

先把语言语义加入核心。工具链只能使用公共源、AST、诊断、模块元数据和调试器 API；工具链查询不得绕过边界检查私有编译器或 VM 状态。

新功能需要同步更新公共结果/选项类型（源、范围、版本和失败语义）、直接服务/工作区行为、仅在安全且完整时的协议序列化和能力公告、仅真正面向用户的文字本地化，以及聚焦的功能/本地化/传输测试。

LSP 能力必须与真实且安全的处理程序一致。不得将不支持的操作宣传为可用，处理程序也不得伪造编辑或位置。服务器公开补全解析、类型定义、实现、选择范围、文档链接、完整/增量语义令牌，以及文档、范围和输入时格式化。服务器公告的代码操作类型有 `source.formatDocument`、`source.organizeImports` 和 `refactor.rewrite`；只有能安全删除完全重复的导入时才返回整理操作，类型正文空光标位置存在可生成方法时才返回重写操作。范围格式化会把选择扩展到完整物理行，并返回实际替换范围。

## 失败与恢复

格式错误的文档、不完整输入、无效请求、取消、重复目录定义、不支持区域和陈旧工作区状态都属于预期状态。恢复必须保持宿主响应，不能伪造声明、范围、诊断或编辑。

空功能结果不同于协议/传输失败；语言诊断不同于帧错误或无效 JSON-RPC 请求。直接服务、适配器和宿主必须保持这些区分。文档版本未比已跟踪版本更新时应忽略变更；文档干净时应发布空诊断列表；新分析中消失的导入文件必须清除其先前诊断。

## 审查清单

发布前确认公共头/实现、范围/编辑坐标、文档标识/覆盖层/版本、导入诊断和陈旧清理、每一项已公告能力的处理程序与测试、本地化消息/占位符、补全排序与 `sortText` 的一致性及保守 `preselect`、每种区域的内置类型悬停键和不变的标识符／无定义／拒绝重命名、语义令牌图例／词法恢复、精确协议令牌/标识符/路径/源片段，以及相应的工具链/LSP 用户页面。

## 调试与 DAP 覆盖

调试测试应覆盖源/文件加载、覆盖层、条件断点、入口/步进停止原因、输出/错误输出、独立于脚本退出代码的成功状态、局部变量/子值/求值/写入、调用深度限制、JIT 策略快照以及调试器附加选择 `Vm`。

断点测试还应覆盖多行声明／初始化表达式的暂停位置、预处理行映射、不活动和越界失败、同名导入文件，以及编译器暂停标记不消耗指令预算。

DAP 适配器测试应覆盖初始化、启动/附加、断点、配置完成、停止、输出、退出、终止、断开生命周期。仅能在停止回调中调用的方法必须在该回调中测试；活动运行期间断开时，应在 `ConfigurationDone` 返回后恢复并清理。实时绑定指针和序列化目录分别需要进程内/进程外测试。
还应覆盖启动前待绑定断点、稳定 DAP ID、迁移后的已验证行、本地化未验证消息，以及加载后 `reason: "changed"` 的 `breakpoint` 事件。

新的协议适配器必须使用 `VeroScriptDebugSession` 与 `VeroScriptDapAdapter`，不得重复实现编译器、VM 检查、断点解析或值生命周期。传输测试应单独验证 JSON/帧，不能改变进程内 DAP 契约。TCP 还应覆盖 IPv4、`Port == 0`、`OnListening`、顺序 `MaxSessions`、正常终止、客户端断开，以及 DAP 请求元数据/区域/脚本参数/标准库根/工作目录/作用域环境/初始输入/集合限制。
