# VeroScriptCli

Command-line hosts for compiling, checking, running and packaging scripts, plus the language server and debug adapter.

Initialize a project with `veroscript project init --path ./my-project`, then run
`veroscript build --path ./my-project`. Existing files are preserved. See the
[minimal project example](Resources/Examples/Project/README.md).
