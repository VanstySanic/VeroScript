# 도구 체인

VeroScript 도구 체인은 검사와 실행, 패키지, 디버깅, AOT, 호스트 바인딩과 각 호스트용 SDK를 다룹니다.

## 문서

- [예제 색인](../../../../../VeroScript/Resources/Docs/User/ko-KR/examples.md)
- [C++ SDK](../../../../../Extensions/Language/Cpp/Resources/Docs/User/ko-KR/index.md): 네이티브 임베딩, 호스트 바인딩, AOT 및 C++ 도구.
- [명령줄 도구](../../../../../VeroScriptCli/Resources/Docs/User/ko-KR/index.md)
- [패키지와 배포](../../../../../VeroScriptCli/Resources/Docs/User/ko-KR/packages.md)
- [디버깅](../../../../../VeroScriptTooling/Resources/Docs/User/ko-KR/debugging.md)
- [Tooling 모듈](../../../../../VeroScriptTooling/Resources/Docs/User/ko-KR/index.md): analyzer, LSP, workspace와 DAP.
- [Language Server](../../../../../VeroScriptTooling/Resources/Docs/User/ko-KR/lsp.md): 전송, 수명 주기, 기능, 동기화, 설정 및 현지화.
- [WebAssembly/WASM SDK](../../../../../Extensions/Platform/WebAssembly/Resources/Docs/User/ko-KR/index.md)
- [Python SDK](../../../../../Extensions/Language/Python/Resources/Docs/User/ko-KR/index.md)
- [C# SDK](../../../../../Extensions/Language/CSharp/Resources/Docs/User/ko-KR/index.md)
- [Interop SDK](../../../../../VeroScriptInterop/Resources/Docs/User/ko-KR/index.md)
- [진단 지역화](../../../../../VeroScript/Resources/Docs/User/ko-KR/localization.md)

도구 체인 명령은 언어 버전과 호환되는 것을 사용하세요. `veroscript --version`으로 설치 버전을 확인하며, 진단 언어는 `--lang` 또는 `VERO_LANG`으로 선택합니다.
