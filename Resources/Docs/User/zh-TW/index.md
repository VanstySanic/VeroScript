# VeroScript 文件

[GitHub 原始碼儲存庫](https://github.com/VanstySanic/VeroScript)

VeroScript 是面向嵌入式情境的指令碼語言。依步驟學習工作，請選擇教學；查詢語法、公開 API、設定和限制，請選擇參考文件。

跨平台部署包括 Windows、Linux、macOS 桌面 Runtime 與 SDK、實驗性的 Android/iOS 嵌入適配器，以及面向瀏覽器和其他 JavaScript 宿主的 WebAssembly SDK。請選擇符合目標作業系統與 CPU 架構的套件；各模組指南說明其相依性與可用後端。
