# 工具鏈

VeroScript 工具鏈涵蓋腳本檢查與執行、套件建置、除錯、AOT 產生、繫結目錄、宿主整合，以及面向不同宿主環境的 SDK。

## 文件目錄

- [範例索引](../../../../../VeroScript/Resources/Docs/User/zh-TW/examples.md)
- [C++ SDK](../../../../../Extensions/Language/Cpp/Resources/Docs/User/zh-TW/index.md)：原生嵌入、宿主繫結、AOT，以及 C++ 宣告與轉換工具。
- [命令列工具](../../../../../VeroScriptCli/Resources/Docs/User/zh-TW/index.md)
- [套件與發佈](../../../../../VeroScriptCli/Resources/Docs/User/zh-TW/packages.md)
- [除錯](../../../../../VeroScriptTooling/Resources/Docs/User/zh-TW/debugging.md)
- [Tooling 模組](../../../../../VeroScriptTooling/Resources/Docs/User/zh-TW/index.md)：分析器、格式化、LSP、工作區查詢和 DAP。
- [語言伺服器](../../../../../VeroScriptTooling/Resources/Docs/User/zh-TW/lsp.md)：傳輸、生命週期、能力、同步、設定和在地化。
- [WebAssembly/WASM SDK](../../../../../Extensions/Platform/WebAssembly/Resources/Docs/User/zh-TW/index.md)
- [Python SDK](../../../../../Extensions/Language/Python/Resources/Docs/User/zh-TW/index.md)
- [C# SDK](../../../../../Extensions/Language/CSharp/Resources/Docs/User/zh-TW/index.md)
- [Interop SDK](../../../../../VeroScriptInterop/Resources/Docs/User/zh-TW/index.md)
- [診斷在地化](../../../../../VeroScript/Resources/Docs/User/zh-TW/localization.md)

工具鏈命令應與語言版本保持相容。用 `veroscript --version` 檢查已安裝版本；診斷語言可透過 `--lang` 或 `VERO_LANG` 選擇。
