# VeroScript documentation

[Source code on GitHub](https://github.com/VanstySanic/VeroScript)

VeroScript is an embeddable scripting language. Choose a tutorial to learn a task, or a reference to look up syntax, public APIs, configuration and limits.

Cross-platform deployment includes desktop Runtime and SDK packages for Windows, Linux and macOS, experimental Android/iOS embedding adapters, and a WebAssembly SDK for browsers and other JavaScript hosts. Choose the package for the target OS and CPU architecture; each module guide defines its dependencies and available backends.
