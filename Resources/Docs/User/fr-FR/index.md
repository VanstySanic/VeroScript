# Documentation VeroScript

[Code source sur GitHub](https://github.com/VanstySanic/VeroScript)

VeroScript est un langage de script embarquable. Choisissez un tutoriel pour apprendre une tâche ou une référence pour consulter la syntaxe, les API publiques, la configuration et les limites.

Le déploiement multiplateforme comprend les distributions Runtime et SDK pour Windows, Linux et macOS, des adaptateurs d’intégration Android/iOS expérimentaux et un SDK WebAssembly pour les navigateurs et autres hôtes JavaScript. Choisissez le paquet correspondant au système et à l’architecture cibles ; chaque guide de module précise ses dépendances et les moteurs disponibles.
