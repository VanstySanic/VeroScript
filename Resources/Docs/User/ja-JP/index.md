# VeroScript ドキュメント

[GitHub のソースコード](https://github.com/VanstySanic/VeroScript)

VeroScript は組み込み向けのスクリプト言語です。作業を順に学ぶにはチュートリアルを、構文、公開 API、設定、制限を調べるにはリファレンスを選んでください。

クロスプラットフォーム展開では Windows、Linux、macOS 向けのデスクトップ Runtime と SDK、実験段階の Android/iOS 組み込みアダプター、ブラウザーやその他の JavaScript ホスト向けの WebAssembly SDK を提供します。対象の OS と CPU アーキテクチャに合うパッケージを選び、依存関係と利用できるバックエンドは各モジュールのガイドで確認してください。
