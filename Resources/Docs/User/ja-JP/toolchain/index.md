# ツールチェーン

VeroScript のツールチェーンは、検査と実行、パッケージ、デバッグ、AOT、ホストバインディング、各種 SDK を扱います。

## ドキュメント

- [サンプル一覧](../../../../../VeroScript/Resources/Docs/User/ja-JP/examples.md)
- [C++ SDK](../../../../../Extensions/Language/Cpp/Resources/Docs/User/ja-JP/index.md)：ネイティブ埋め込み、ホスト バインディング、AOT、C++ ツール。
- [コマンドラインツール](../../../../../VeroScriptCli/Resources/Docs/User/ja-JP/index.md)
- [パッケージと配布](../../../../../VeroScriptCli/Resources/Docs/User/ja-JP/packages.md)
- [デバッグ](../../../../../VeroScriptTooling/Resources/Docs/User/ja-JP/debugging.md)
- [Tooling モジュール](../../../../../VeroScriptTooling/Resources/Docs/User/ja-JP/index.md)：analyzer、LSP、workspace、DAP。
- [Language Server](../../../../../VeroScriptTooling/Resources/Docs/User/ja-JP/lsp.md)：transport、lifecycle、capability、sync、設定、localization。
- [WebAssembly/WASM SDK](../../../../../Extensions/Platform/WebAssembly/Resources/Docs/User/ja-JP/index.md)
- [Python SDK](../../../../../Extensions/Language/Python/Resources/Docs/User/ja-JP/index.md)
- [C# SDK](../../../../../Extensions/Language/CSharp/Resources/Docs/User/ja-JP/index.md)

- [診断のローカライズ](../../../../../VeroScript/Resources/Docs/User/ja-JP/localization.md)

ツールチェーンのコマンドは言語バージョンと互換性のあるものを使用してください。`veroscript --version` でインストール済みバージョンを確認できます。診断言語は `--lang` または `VERO_LANG` で選択します。
