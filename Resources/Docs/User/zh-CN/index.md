# VeroScript 文档

[GitHub 源码仓库](https://github.com/VanstySanic/VeroScript)

VeroScript 是面向嵌入式场景的脚本语言。按步骤学习任务，请选择教程；查询语法、公开 API、配置和限制，请选择参考文档。

跨平台部署包括 Windows、Linux、macOS 桌面 Runtime 与 SDK、实验性的 Android/iOS 嵌入适配器，以及面向浏览器和其他 JavaScript 宿主的 WebAssembly SDK。请选择匹配目标操作系统与 CPU 架构的包；各模块指南说明其依赖和可用后端。
