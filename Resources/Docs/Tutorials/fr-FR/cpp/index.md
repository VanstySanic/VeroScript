# Tutoriels de la chaîne C++

Ce module présente le flux d’intégration native de VeroScript avec C++. Il
constitue un point d’entrée autonome pour les lecteurs qui disposent déjà
d’un hôte C++ ou qui doivent choisir entre intégration runtime, génération de
bindings, conversion de source et génération AOT.

## Commencer ici

Commencez par [18 : choisir les modules de la chaîne C++](01-cpp-toolchain.md).
Ce tutoriel aide à choisir le bon module, à produire et vérifier un catalogue
de bindings, à convertir un sous-ensemble C++ pris en charge et à générer une
source native depuis VeroScript.

Avant de lancer le tutoriel, consultez la [documentation du SDK C++](../../../../../Extensions/Language/Cpp/Resources/Docs/User/fr-FR/index.md)
pour connaître les frontières entre modules et les hypothèses du flux de
travail.

- [Intégration runtime](../../../../../Extensions/Language/Cpp/Resources/Docs/User/fr-FR/embedding.md) : sessions hôte,
  exécution de scripts, bindings et cycle de vie.
- [Génération de bindings](../../../../../Extensions/Language/Cpp/Resources/Docs/User/fr-FR/bindgen.md) : catalogues,

- [Conversion C++ vers VeroScript](../../../../../Extensions/Language/Cpp/Resources/Docs/User/fr-FR/transpiler.md) :

- [Génération AOT](../../../../../Extensions/Language/Cpp/Resources/Docs/User/fr-FR/aot.md) : source C++17 générée,
