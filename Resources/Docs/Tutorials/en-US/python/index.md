# Python source-tool tutorials

This module is for developers who have typed Python declarations and want to
inspect them, expose them as VeroScript host bindings, or convert them into
VeroScript source. Read the [Python SDK docs](../../../../../Extensions/Language/Python/Resources/Docs/User/en-US/index.md)
for complete boundaries and signatures.

## Recommended path

- [01: Build a Python source-tool pipeline](01-python-source-tools.md): parse,
  generate a Binding Catalog, and transpile a typed Python project.

The Python runtime SDK and Python AOT backend are separate execution choices.
Use their documentation when Python is the host runtime or the generated
Python program is the delivery artifact.
