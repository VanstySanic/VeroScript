# C++ toolchain tutorials

This module covers the native C++ integration workflow around VeroScript. It
is a self-contained entry point for readers who already have a C++ host or who
need to choose between embedding, binding generation, source conversion, and
AOT generation.

## Start here

Begin with [18: Choose and use the C++ toolchain modules](01-cpp-toolchain.md).
It helps you choose the correct module, generate and validate a binding
catalog, convert a supported C++ source subset, and generate native source
from VeroScript.

Before running the tutorial, read the [C++ SDK documentation](../../../../../Extensions/Language/Cpp/Resources/Docs/User/en-US/index.md)
for module boundaries and supported workflow assumptions.

## Reference map

- [Embedding](../../../../../Extensions/Language/Cpp/Resources/Docs/User/en-US/embedding.md): host sessions, script runs,
  bindings, and lifecycle boundaries.
- [Binding generation](../../../../../Extensions/Language/Cpp/Resources/Docs/User/en-US/bindgen.md): catalogs,
  references, project manifests, and supported declarations.
- [C++ to VeroScript conversion](../../../../../Extensions/Language/Cpp/Resources/Docs/User/en-US/transpiler.md):
  single-file and project conversion, source maps, and limitations.
- [AOT generation](../../../../../Extensions/Language/Cpp/Resources/Docs/User/en-US/aot.md): generated C++17 source,
  source bundles, and the VM/AOT boundary.
