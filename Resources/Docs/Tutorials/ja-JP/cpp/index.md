# C++ ツールチェーン チュートリアル

このモジュールでは、VeroScript と C++ を統合するネイティブ ワークフローを
扱います。すでに C++ host を持っている場合や、embedding、binding 生成、source
変換、AOT 生成のどれを使うか選びたい場合の独立した入口です。

## ここから始める

[18: C++ ツールチェーン モジュールを選ぶ](01-cpp-toolchain.md) から始めてください。
このチュートリアルでは、目的に合うモジュールの選択、binding catalog の生成と
検証、対応する C++ source の変換、VeroScript から native source を生成する流れを
実行します。

実行前に、モジュールの境界とワークフローの前提を[C++ SDK リファレンス](../../../../../Extensions/Language/Cpp/Resources/Docs/User/ja-JP/index.md)
で確認してください。

## リファレンス マップ

- [Embedding](../../../../../Extensions/Language/Cpp/Resources/Docs/User/ja-JP/embedding.md): host session、script 実行、
  binding、ライフサイクルの境界。
- [Binding 生成](../../../../../Extensions/Language/Cpp/Resources/Docs/User/ja-JP/bindgen.md): catalog、reference、project
  manifest、対応する宣言。
- [C++ から VeroScript への変換](../../../../../Extensions/Language/Cpp/Resources/Docs/User/ja-JP/transpiler.md): 単一入力と
  project の変換、source map、制限事項。
- [AOT 生成](../../../../../Extensions/Language/Cpp/Resources/Docs/User/ja-JP/aot.md): 生成される C++17 source、source bundle、
  VM/AOT の境界。

完全な学習順序は[チュートリアルのメイン インデックス](../index.md)に戻って確認
できます。
