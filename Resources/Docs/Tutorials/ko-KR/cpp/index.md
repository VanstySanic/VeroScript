# C++ 도구 체인 튜토리얼

이 모듈은 VeroScript와 C++를 연결하는 네이티브 통합 흐름을 다룹니다. 이미 C++
호스트가 있거나 임베딩, 바인딩 생성, 소스 변환, AOT 생성 중 알맞은 방식을 선택해야
하는 독자를 위한 독립적인 시작점입니다.

## 여기서 시작하기

[18: C++ 도구 체인 모듈 사용하기](01-cpp-toolchain.md)부터 시작하십시오. 이 튜토리얼은
목적에 맞는 모듈 선택, 바인딩 카탈로그 생성과 검증, 지원되는 C++ 소스 변환, VeroScript에서
네이티브 소스 생성까지의 흐름을 안내합니다.

실행하기 전에 모듈 경계와 작업 흐름의 전제를 [C++ SDK 레퍼런스](../../../../../Extensions/Language/Cpp/Resources/Docs/User/ko-KR/index.md)에서
확인하십시오.

## 레퍼런스 맵

- [임베딩](../../../../../Extensions/Language/Cpp/Resources/Docs/User/ko-KR/embedding.md): 호스트 세션, 스크립트 실행, 바인딩과
  수명 주기 경계.
- [바인딩 생성](../../../../../Extensions/Language/Cpp/Resources/Docs/User/ko-KR/bindgen.md): 카탈로그, API reference, 프로젝트
  manifest와 지원되는 선언.
- [C++에서 VeroScript로 변환](../../../../../Extensions/Language/Cpp/Resources/Docs/User/ko-KR/transpiler.md): 단일 입력과 프로젝트
  변환, source map과 제한 사항.
- [AOT 생성](../../../../../Extensions/Language/Cpp/Resources/Docs/User/ko-KR/aot.md): 생성되는 C++17 소스, source bundle과
  VM/AOT 경계.

전체 학습 순서는 [튜토리얼 메인 인덱스](../index.md)로 돌아가 확인하십시오.
