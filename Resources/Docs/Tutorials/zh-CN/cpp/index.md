# C++ 工具链教程

本模块介绍 VeroScript 与 C++ 的原生集成流程。它既可以作为完整教程的一个入口，
也可以单独发布，适合已经拥有 C++ 宿主，或需要在嵌入、绑定生成、源码转换和 AOT
生成之间做选择的读者。

## 从这里开始

请先阅读[第 18 篇：选择和使用 C++ 工具链模块](01-cpp-toolchain.md)。这篇教程会带你
选择正确的模块，生成并校验绑定目录，转换受支持的 C++ 源码，并从 VeroScript 生成
原生源码。

运行教程前，请先阅读 [C++ SDK 文档](../../../../../Extensions/Language/Cpp/Resources/Docs/User/zh-CN/index.md)，了解模块边界和
工作流前提。

## 参考地图

- [嵌入与宿主集成](../../../../../Extensions/Language/Cpp/Resources/Docs/User/zh-CN/embedding.md)：宿主工作阶段、脚本运行、
  绑定和生命周期边界。
- [绑定生成](../../../../../Extensions/Language/Cpp/Resources/Docs/User/zh-CN/bindgen.md)：绑定目录、API 参考、项目清单和支持的
  C++ 声明。
- [C++ 到 VeroScript 的转换](../../../../../Extensions/Language/Cpp/Resources/Docs/User/zh-CN/transpiler.md)：单文件与项目转换、
  源映射和限制条件。
- [AOT 生成](../../../../../Extensions/Language/Cpp/Resources/Docs/User/zh-CN/aot.md)：生成的 C++17 源码、源码包以及 VM/AOT 边界。

如需返回完整学习路线，请查看[教程总目录](../index.md)。
