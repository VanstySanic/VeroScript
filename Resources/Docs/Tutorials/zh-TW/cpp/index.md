# C++ 工具鏈教學

本模組介紹 VeroScript 與 C++ 的原生整合流程。它可以作為完整教學的一個入口，
也可以獨立發佈，適合已經擁有 C++ 宿主，或需要在嵌入、繫結產生、原始碼轉換和 AOT
產生之間做選擇的讀者。

## 從這裡開始

請先閱讀[第 18 篇：選擇和使用 C++ 工具鏈模組](01-cpp-toolchain.md)。這篇教學會帶你
選擇正確的模組，產生並校驗繫結目錄，轉換支援的 C++ 原始碼，並從 VeroScript 產生
原生原始碼。

執行教學前，請先閱讀 [C++ SDK 文件](../../../../../Extensions/Language/Cpp/Resources/Docs/User/zh-TW/index.md)，了解模組邊界和
工作流程前提。

## 參考地圖

- [嵌入與宿主整合](../../../../../Extensions/Language/Cpp/Resources/Docs/User/zh-TW/embedding.md)：宿主工作階段、腳本執行、
  繫結和生命週期邊界。
- [繫結產生](../../../../../Extensions/Language/Cpp/Resources/Docs/User/zh-TW/bindgen.md)：繫結目錄、API 參考、專案清單和支援的
  C++ 宣告。
- [C++ 到 VeroScript 的轉換](../../../../../Extensions/Language/Cpp/Resources/Docs/User/zh-TW/transpiler.md)：單一檔案與專案轉換、
  原始碼對映和限制條件。
- [AOT 產生](../../../../../Extensions/Language/Cpp/Resources/Docs/User/zh-TW/aot.md)：產生的 C++17 原始碼、原始碼包以及 VM/AOT 邊界。

如需返回完整學習路線，請查看[教學總目錄](../index.md)。
