# VeroScript 코드 규약(잠정)

적용 범위: [VeroScript 프로젝트 개발 및 기여](README.md).

VeroScript의 타입 배치와 논리 구획은 [CPP.md](CPP.md)를 참고합니다. 이 문서는 현재 직접 확정할 수 있는 VeroScript 작성법만 정의합니다. 언어나 formatter에 고유한 세부 사항은 추후 보완할 수 있습니다.

## 형식

- `else`, `else if`, `catch`, `finally`, `do…while` 끝의 `while`은 [GENERAL.md](GENERAL.md)에 따라
  새 줄에 둡니다. 블록의 여는 중괄호도 절에 맞춘 독립된 줄에 둡니다.
- 논리 계층마다 실제 Tab 하나를 사용하고 기본 표시 너비는 네 칸으로 하며 [GENERAL.md](GENERAL.md)의 들여쓰기 규칙을 따릅니다.
- 네임스페이스, 타입, 메서드, 조건문, 반복문, 지역 스코프는 한 단계 들어갈 때마다 들여쓰기도 한 단계 증가시킵니다.
- 여는 중괄호는 별도 줄에 두고 닫는 중괄호는 대응하는 선언 또는 제어문에 맞춥니다.
- 실행 본문이 있는 조건문과 반복문에 중괄호를 사용합니다. 유일한 예외는 본문이 직접적인 `return` 하나뿐인 한 줄 가드문입니다. `else` 체인, 로그, 정리 작업 또는 다른 문장과 조합해서는 안 됩니다.
- 모든 `switch`에는 `default`가 있어야 합니다. 각 `case`와 `default`의 일반 실행 내용은 독립적인 중괄호 스코프 안에 둡니다. 현재 메서드를 바로 종료하는 직접적인 `return` 하나만 있는 분기는 이 블록을 생략할 수 있습니다.
- 명시적 `fallthrough;`는 분기의 중괄호 블록 뒤에서 레이블에 직접 속하는 마지막 문장이어야 합니다. 블록, 조건문, 반복문 안에 중첩하지 않습니다. 이는 언어 계약에 따른 예외이며 나머지 실행 내용은 독립 스코프 안에 둡니다.
- `class`, `struct`, `interface`, `enum` 타입 선언은 끝에 세미콜론을 붙입니다.

## 타입 배치

타입 내부는 다음 순서로 배치합니다.

1. 타입 관계와 별칭
2. `public`, `protected`, `private` 영역(이 순서)
3. 각 영역의 상속 메서드
4. 내부 타입: `enum` → `struct` → 기타 타입 → `class`
5. 해당 타입의 메서드
6. 멤버 변수

- 상속/인터페이스 메서드는 기반 클래스나 인터페이스의 상속 순서로 배치합니다. 필요하면 `//~ Begin <Name> Interface` / `//~ End <Name> Interface` 쌍 주석으로 구획을 설명합니다.
- 같은 파일에 여러 최상위 타입이 있을 때도 완전한 타입 의존성 충돌이 없다면 `enum` → `struct` → 기타 → `class` 순서로 배치합니다.
- 현재 이 규약은 VeroScript의 전방 선언을 규정하지 않습니다. 네이티브 언어 문법이 이를 지원하는지 아직 확인되지 않았습니다. C++ 규약에 이 규칙이 있다는 이유만으로 VeroScript에 전방 선언을 도입해서는 안 됩니다. 문법 확인 후 별도로 보완합니다.

## 이름과 주석

- 타입과 인터페이스는 PascalCase를, 함수, 필드, 매개변수, 지역 변수는 lowerCamelCase를 사용합니다.
- 주석은 [GENERAL.md](GENERAL.md)를 따릅니다. 언어 기능, 제약, 소유권, 예제 목적을 설명하며 코드의 표면적 의미를 반복하지 않습니다.
- 공개 표준 라이브러리와 호스트 바인딩 이름은 호환성 표면에 속하므로 이름 변경은 별도로 평가해야 합니다.

## 길이와 인덱스

컨테이너 길이, 선형 인덱스, 슬라이스 위치와 개수 및 용량에는 `int64`를 사용합니다. Map 키와 작업 ID는 선언된 타입을 유지하며 개수가 64비트가 되었다고 관계없는 API의 타입을 넓히지 마세요. 네이티브 `size_t`나 더 좁은 백엔드 인덱스로 변환하기 전에 부호와 범위를 검사합니다. `int`가 필요하면 범위를 검사하는 축소 변환을 사용하고 할당 제한과 문서화된 결과 없음 값을 유지하세요. 계약 변경 시 표준 라이브러리 선언, 문서 및 회귀 테스트를 함께 갱신합니다.
