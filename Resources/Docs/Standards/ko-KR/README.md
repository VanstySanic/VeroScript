# VeroScript 프로젝트 개발 및 기여 규약

이 규약은 공개적으로 열람할 수 있으며 **VeroScript 프로젝트의 개발과 기여에만 적용됩니다**. 언어 명세, SDK 사용 요건 또는 MIT 라이선스의 추가 조건이 아닙니다. 다른 프로젝트에서 VeroScript를 사용, 통합 또는 수정할 때 이 코딩 관례를 채택하거나 자기 코드의 저작권자를 이 프로젝트의 권리자로 표시할 필요가 없습니다. 기존 저작권 및 라이선스 문구는 [MIT 라이선스](../../../../LICENSE)와 해당 타사 라이선스에 따라 보존합니다.

Standards는 소스 저장소에 유지하며 전체 `All` 문서에 개발자 자료로 포함합니다. `User` 문서, Resources의 사용자 문서, Runtime/SDK/확장 배포 파일 및 설치 관리자에는 Standards를 포함하지 않습니다.

이 문서는 본 프로젝트의 **수동 관리 코딩 및 배포 규칙**입니다. 코딩 규칙은 저장소가 소유하고 직접 유지하는 소스 코드에 적용하며 VeroScript 코어, 도구, 언어 확장, 기타 네이티브 및 애플리케이션 모듈을 포함합니다. [PACKAGING.md](PACKAGING.md)는 공식 배포 모음과 검증을 다룹니다.

유일한 유지 관리 원본은 `Resources/Docs/Standards/`입니다. 규칙을 정하는 정본은 `zh-CN`이며 다른 언어는 동등한 번역입니다. 번역으로 규칙을 추가하거나 변경하지 않습니다. 규칙은 유지 관리자의 명시적 결정에 따르며 기존 코드, 외부 관례 또는 도구 기본값에서 추론하지 않습니다. 이전 규칙은 비교를 위해 버전 관리에 보존하며 새 코드나 실질적으로 수정한 코드에는 현행 승인 규칙만 적용합니다.

규칙은 계속 정비 중입니다. 확인된 규칙은 준수하되, 명시되지 않은 내용을 임의로 필수 요구 사항으로 확대하지 않습니다. 새 규칙은 해당 언어나 주제에 가장 가까운 파일에 추가합니다.

## 요구 수준

- **필수**: 새 코드와 실질적으로 변경하는 코드는 반드시 충족해야 합니다.
- **권장**: 기본적으로 채택합니다. 언어 제약, 호환성 또는 가독성 때문에 벗어나면 국소적 일관성을 유지하고 이유를 설명합니다.
- **필요에 따라**: 구조 이해, 유지 관리성 또는 호출자의 이해를 개선할 때만 사용하며 기계적이고 반복적인 상용구를 만들지 않습니다.
- **잠정**: 현재 권장 기본값이며 유지 관리자가 보완하거나 교체할 수 있습니다.

## 적용 범위와 이관

- 코딩 규칙은 저장소 소유의 수동 관리 소스 코드와 소스 주석에 적용합니다. 패키징과 배포는 [PACKAGING.md](PACKAGING.md)를 따릅니다.
- `ThirdParty/`, 생성 디렉터리와 파일, 파서 테스트용 원시 입력 픽스처는 강제 이관 대상이 아닙니다.
- 새 파일은 해당 규칙 전체를 준수합니다. 기존 파일에서는 추가하거나 관련된 코드를 우선하며, 기능 변경과 무관한 코드를 대규모로 재배치하지 않습니다.
- 유효한 언어, ABI, 프로토콜 및 빌드 계약은 형식 규칙보다 우선합니다. 충돌하면 계약을 유지하고 해당 규칙에 예외를 기록합니다.

## 유지 관리

규칙 변경은 작고 명확하게 작성하고 규칙, 범위, 필요한 예와 예외를 설명합니다. 과거 한 파일의 우연한 작성 방식을 전역 규칙으로 승격하지 않습니다.

- 먼저 `zh-CN` 정본을 수정하고 같은 변경에서 나머지 다섯 언어를 동기화합니다. 요구 수준, 범위, 예외 및 잠정 상태를 동일하게 유지합니다.
- 이곳의 해당 언어에서 본문을 관리합니다. 규칙 변경 시 예를 검토하며 기존 코드에서 새 규칙을 추론하지 않습니다.
- 규약은 `Resources/Docs/Standards/<locale>`에서 관리합니다. `zh-CN`이 규칙을 정의하고 나머지 다섯 언어는 동등하게 유지합니다. 변경 후 `python Resources/Tools/Packaging/veroscript_docs.py check`와 `check-collection`을 실행합니다. 규약 원본은 개발자 자료로 `All`에만 포함하며 `User` 또는 기능 배포물에는 포함하지 않습니다.
- 코드, API, 프로토콜 필드, 명령 및 두 줄 SPDX 머리 문구는 번역하지 않습니다. 코드 예의 주석도 영어를 유지합니다.
