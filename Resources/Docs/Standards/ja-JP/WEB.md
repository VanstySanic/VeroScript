# TypeScript・JavaScript コーディング規約（暫定）

適用範囲：[VeroScript 本プロジェクトの開発・貢献](README.md)。

TypeScript/JavaScript は [GENERAL.md](GENERAL.md) の区分、コメント、必要最小限の説明に従います。以下の節の改行規則は必須です。その他の波括弧配置は暫定的に各モジュールの既存の書式に従います。

## 現在の暫定規則

- `else`、`else if`、`catch`、`finally`、`do…while` 末尾の `while` は [GENERAL.md](GENERAL.md)
  に従って改行します。ブロックの開始波括弧も独立行で節に揃えます。
- 論理階層ごとに実際の Tab を一つ使い、既定の表示幅を 4 桁とします。[GENERAL.md](GENERAL.md) の字下げ規則に従います。
- 型、関数、条件、ループ、`switch` を意味ごとに区分し、無意味な一行圧縮を避けます。
- すべての `switch` に `default` が必要です。TypeScript の網羅性検査はその中で行えますが、静的検査を理由に省略しません。未知値を明確に処理します。
- 各 `case`/`default` の本体は独立した波括弧付きスコープとし、暗黙の貫通を使いません。意図的な共通処理は隣接説明を付けます。唯一の例外は単一経路が直接 `return` で関数を終了し、他の文を含まない場合です。
- 制御分岐はすべて波括弧を使います。唯一の例外は直接 `return` または `return <式>` だけの一行ガードで、`else`、ログ、解放、他の文と組み合わせません。
- モジュールの TypeScript 型は `enum` → `interface` → `type`/他の別名 → `class` の順です。ジェネリックインターフェースとクラスは自身の分類に従います。JavaScript で対応する型宣言がない場合も、export 関係と依存で同等の明確さを保ちます。
- クラスは C++ の全体順に対応別名・定数、継承・インターフェース実装、内部型、メソッド、フィールドを置きます。フィールドは対応するアクセス意味領域の末尾です。
- 複数インターフェース実装やアダプター区画には、必要に応じて対の `//~ Begin <Name> Interface` / `//~ End <Name> Interface` を使います。
- export 型、インターフェース、クラスは PascalCase、関数、フィールド、引数、局所変数は camelCase にします。外部プロトコルフィールドは契約名を維持します。
- 公開データ、エラー、資源解放の意味は型または必要なコメントで表します。

## 今後の補足

波括弧書式、引用符・セミコロン・末尾カンマ、`readonly`、非同期キャンセル、Wasm 資源の寿命、型検査要件を決定できます。
