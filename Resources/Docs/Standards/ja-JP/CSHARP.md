# C# コーディング規約（暫定）

適用範囲：[VeroScript 本プロジェクトの開発・貢献](README.md)。

C# は [GENERAL.md](GENERAL.md) の原則と、[CPP.md](CPP.md) の「関係、型、メソッド、データ」の構造に従います。C# の構文に対応しない部分は本ファイルを優先します。

## 書式

- `else`、`else if`、`catch`、`finally`、`do…while` 末尾の `while` は [GENERAL.md](GENERAL.md)
  に従って改行します。ブロックの開始波括弧も独立行で節に揃えます。
- 論理階層ごとに実際の Tab を一つ使い、既定の表示幅を 4 桁とします。[GENERAL.md](GENERAL.md) の字下げ規則に従います。
- ブロック本体を持つ型、メソッド、プロパティ、制御分岐、`switch` は C++ と同じ Allman の波括弧配置にします。
- 一つの直接的で読みやすい式だけのメンバー、アクセサー、局所的な対応付けは `=>` を使えます。複数手順、資源管理、ログ、複雑な制御を隠さず、多段の処理は Allman ブロックにします。
- 本体を持つ `if`、`else`、ループ、`using`、`lock`、`try`、`catch`、`finally` はすべて波括弧を使います。
- 唯一の例外は、直接 `return` または `return <式>` だけの一行ガードです。`else` 連鎖、ログ、解放、その他の文と組み合わせません。`break`、`continue`、`throw` などには波括弧が必要です。
- `switch` 文は `default` を持ちます。`switch` 式は入力を完全に扱い、先行パターンが網羅的と証明されない場合に `_` を置きます。網羅的で `_` が到達不能になる場合は形式のために追加しません。未知値の扱いを明確にし、不明瞭な実行時失敗に依存しません。
- 各 `case`/`default` は独立した波括弧付きスコープにし、暗黙の貫通を使いません。意図的な共通処理は隣接コメントで説明します。唯一の例外は、単一経路が直接 `return` または `return <式>` でメソッドを終了し、ログ、解放、宣言、条件、他の文を含まない場合です。
- `#if` などの指示は囲むコードと同じ階層で、字下げを一段増やしません。

## 型配置

推奨順：

1. 属性は対象に、基底とインターフェースのリストは型宣言に隣接させる；
2. アクセス指定付きメンバーは `public` → `protected internal` → `protected` → `internal` → `private protected` → `private` の順で、可能ならレベルごとに連続領域へまとめる；
3. 各領域では `override` とインターフェース実装を先にする。明示的実装にはアクセス修飾子を付けず、インターフェース継承順で対応区画の先頭に置く；
4. 内部型を `enum` → `struct`/`record struct` → その他 → `class`/`record` の順にする；
5. 独自のコンストラクター、メソッド、プロパティ、イベント；
6. 最後にフィールド。メソッド、プロパティ、内部型の間へ挟まない。

- 明示的インターフェース実装をインターフェースごとに分け、複数メンバーや不明瞭な区画には対の `//~ Begin <Name> Interface` と `//~ End <Name> Interface` を使います。
- インターフェース、基底、独自実装の区画を交互に混在させません。
- 長い実装ファイルでは宣言との順序を追跡可能にし、局所補助型や非公開静的補助メソッドは最も読みやすい位置に置けます。
- `file` はファイル局所のトップレベル型だけに適用し、メンバーアクセス領域の順序には含めません。ジェネリッククラス・構造体はそれぞれの型分類に従い、「その他」へまとめません。

## コメントと命名

- 意味、所有権、スレッド、例外、プロトコル制約を呼び出し側が知る必要のある型、メソッド、プロパティ、フィールドだけにコメントします。
- 自明でない公開 API 契約は XML 文書コメント、短い内部説明は `//` を使います。
- 既存 .NET 命名を維持し、型・メンバーは PascalCase、引数・局所変数は camelCase、非公開フィールドは `_camelCase` にします。
- ネイティブ ABI、JSON、プロトコルのフィールド名は外部契約を維持し、内部の統一のために互換性を壊しません。
