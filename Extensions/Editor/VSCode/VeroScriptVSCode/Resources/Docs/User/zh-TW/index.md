# VeroScript VS Code 擴充功能

部分編輯器版本限制空工作區中的終端程序。如果執行/檢查因腳本工作目錄而被拒絕，請將該目錄作為工作區開啟。執行域附加不使用終端。

## 開始使用

安裝桌面版 VS Code 1.106.0 以上，透過「從 VSIX 安裝」載入本機套件。解壓縮符合擴充功能宿主作業系統與架構的 相容的 Runtime，執行 **VeroScript: 選擇 Runtime**，選擇包含三個程式、stdlib 和 localization 的根目錄。

儲存 .vs 檔案後執行 **執行檔案**、**檢查檔案** 或 **偵錯檔案**。基本著色與片段不需要 Runtime。WSL、SSH、容器需要在遠端宿主安裝相符 Runtime。

## 設定與執行

受信任的工作區可用 `veroscript.lsp.executablePath` 指定主控端提供的 stdio 語言伺服器，路徑遵循共用路徑規則。`veroscript.lsp.arguments` 將陣列的各項原樣傳為獨立引數，保留空格與空字串。未明確設定的編譯選項沿用主控端預設值。入口留空時使用 Runtime 語言伺服器，變更入口或引數會重新啟動伺服器。 自訂語言伺服器繼承擴充功能主控端的環境變數，初始化期限為十秒。

接受命名空間補全後會繼續顯示下一級成員，包括巢狀命名空間；停用 editor.suggestOnTriggerCharacters 時不會自動續彈。VeroScript 預設將 editor.wordBasedSuggestions 設為 off，避免註解中的單字繞過語意篩選；可在 [veroscript] 設定中覆寫。內建範本按輸入前綴比對並進行保守的詞法位置檢查：匯入和入口用於檔案作用域，宣告用於支援的宣告區域，迴圈用於陳述式起點。註解、字串及未完成的運算式中不建議範本；使用者片段仍由 VS Code 管理。擴充功能保留原生篩選與排序欄位，VS Code 也會根據輸入前綴比對。

懸停簽名使用 VeroScript 程式碼區塊，多載、說明與定義位置分段顯示。補全詳情避免重複簽名，並保留原有說明、連結與範例。顏色遵循 VS Code 佈景主題；參數提示中的目前參數仍由原生服務決定。

veroscript.importPaths、implicitImportPaths、defines、predefinedMacros、bindingCatalogPaths 等設定會套用到對應工作區。相對路徑以所屬工作區為基準，沒有工作區時以原始檔目錄為基準。共用路徑支援 workspaceFolder 與環境變數；無法解析時會報錯。每個根目錄、巢狀根與外部檔案各有明確的語言伺服器歸屬。

已設定匯入／標準函式庫目錄及隱式匯入中的開啟檔案，其未儲存內容也會同步給引用方的語言伺服器；診斷與編輯功能仍由檔案所屬上下文提供。相容的 Runtime 主要更新被編輯檔案的診斷；其他引用檔案的診斷會在該檔案重新分析時更新，例如編輯或儲存該引用檔案後。

執行與檢查命令會先提供儲存相關文件的選項。直接執行工作遵循 task.saveBeforeRun。工作以原生處理程序傳遞獨立參數並保留結束代碼。陣列與明確指定的工作 env 會取代繼承值。VERO_PATH、VERO_STDLIB_PATH 請改用明確的路徑設定。

## 偵錯與附加

F5 使用 VM DAP，可設定 stopOnEntry、args、input、cwd、env 與編譯選項。偵錯主控台用於運算式求值；input 提供初始標準輸入，互動輸入請使用一般執行工作。無偵錯執行請使用 **執行檔案**。

program 模式的 attach 使用 program、host、port 連線至已接聽的 TCP DAP 宿主，不需要本機 Runtime，不注入工作區設定、cwd 或 env。此模式在宿主載入程式，不附加至執行中的 VM/PID。路徑必須在兩端有效。目前不支援函式、例外、記錄、命中次數中斷點、反向執行、inlay hints 和 CodeLens。

從命令選擇區或 .vs 檔案選單執行 **VeroScript: 附加至宿主**。使用所選或目前已儲存的指令碼；沒有合適檔案時開啟檔案選擇器，然後詢問位址與連接埠，預設 127.0.0.1:4711。任一輸入取消都不會啟動工作階段。附加前檢查相關來源的儲存狀態，啟動後停在入口；IPv6 不帶方括號。F5 設定產生及 launch.json 補全也提供 attach 範本。固定入口、引數及明確編譯選項可儲存為 launch.json 設定。

連線至宿主應用程式提供的相容 TCP DAP 端點。原生程式碼使用對應偵錯器，腳本使用本外掛偵錯。

### 執行域線上附加

執行 **VeroScript: 附加至執行域** 或使用 launch.json 範本。request 為 attach、attachMode 為 domain，提供 host/port，可選 domainId 校驗目標身分；留空或省略時使用端點提供的執行域。不需要開啟檔案或本機 Runtime。此模式不會儲存、載入或重新啟動指令碼，拒絕 program、編譯/執行覆寫參數及 debugServer。同一偵錯連線可跨越多次宿主呼叫。 宿主結束偵錯工作階段後，外掛會完成斷開流程，不要求取消腳本執行。

端點必須支援執行域線上附加，否則連線失敗且不會載入程式。初始連線及初始化期限為 10 秒。請在輸出中確認宿主／執行域身分及原始碼／繫結修訂；修訂是不透明識別碼，須自行核對來源和 API 中繼資料，目前沒有自動比較或 LSP 同步。中斷連線後，執行和取消仍由宿主管理。連線遺失會結束偵錯，不自動重新連線；不能接管已在執行 JIT 程式碼的 VM。

暫停、逐步執行、運算式求值、條件中斷點和變數修改取決於宿主支援的功能；不支援的請求會明確回報錯誤，一般中斷點仍可使用。停止／中斷連線會結束偵錯連線，需要取消腳本執行時，請透過宿主應用程式操作。


## 可選 JIT 模組

Runtime 與 JIT 後端獨立分發。veroscript.run.jitBackendPath 為選填，用於在一般執行中固定相容的程式庫檔案或目錄。留空會省略 CLI 路徑覆寫，繼承模組環境的選擇；未設定後端時預設為 auto。停用 JIT 或沒有可用自動候選時，mixed 使用 VM，強制 jit 在執行前失敗。工作的 jitBackendPath 可覆寫設定，空字串清除繼承值。模組相對路徑以所屬工作區或原始檔目錄為基準，不受 cwd 影響，並支援執行路徑變數。檢查、LSP 和本機 VM 偵錯不載入此模組；launch/attach 拒絕 jitBackendPath。線上執行域由宿主選擇後端。目錄探索及 ABI 驗證由原生載入器負責；LSP/DAP 的 jitCapability 表示核心服務契約，並非已安裝的後端。

## 記憶體型別與偵錯檢視

使用相符的 Runtime 時，`std::memory` 型別及泛型呼叫由原生工具提供補全、懸停及參數提示。偵錯時可在變數面板展開緩衝區和視圖的檢視欄位；這些欄位唯讀，繼續執行或單步後舊控制代碼失效。宿主提供的記憶體中繼資料保持原樣轉送；目前不支援任意記憶體讀寫請求或專用記憶體編輯器。

## 目前語言工具與模組原始碼

原始字串 `r"..."` 可以跨行，反斜線依原文保留，遇到後續第一個引號結束；著色和範本篩選無需 Runtime 也遵循此規則。`.vslib` 程式庫檔案的變更（包括大寫副檔名）會轉送給語言伺服器。

伺服器公布模組環境及原始碼請求方法時，跳轉會把 `veroscript-module:` 文件開啟為唯讀原始碼快照。不同工作區的同名原生路徑保持隔離。伺服器重新啟動或編譯快照變更後，請從所屬原始檔重新跳轉；舊檢視保留原來的文字。這些檢視用於原始碼顯示和語法著色，不提供編輯或快照內的額外語言查詢。

原生編譯／註記處理器和模組環境需要由 LSP／DAP 宿主提供。預設 Runtime 服務不會自動匯入宿主應用程式的處理器或 CLI 套件環境。`bindingCatalogPaths` 提供中繼資料，包括撰寫擴充時匯出的編譯服務目錄；它不會安裝回呼或處理器。專案依賴這些能力時，請使用設定相符的宿主服務。

註記名稱遵循宿主定義或目錄的 `caseSensitive` 策略；忽略大小寫時僅折疊 ASCII 名稱。外掛保留標準名稱及原生簽章參數標籤，參數名稱仍區分大小寫。修改既有 `bindingCatalogPaths` 檔案會重新載入中繼資料，無須重新啟動伺服器。整理匯入會套用伺服器傳回的精確編輯，保留註解、原始字串、未啟用分支及現有換行符號。

## 大括號配置與型別暫留提示

在空宣告區塊或控制區塊中按 Enter，會將同一行的左大括號移到獨立一行，並縮排游標；輸入中的 `void a{}` 也支援。原本已換行的括號、註解、字串和有歧義的初始化運算式使用一般換行。沿用 VS Code 縮排、換行字元和復原，支援條件一致的多游標；混合位置使用一般換行。完成清單、程式碼片段和內嵌建議保留各自的 Enter 行為。關閉 `veroscript.bracesOnNewLine` 可全面恢復一般換行。此編輯行為無需 Runtime，不改變整份文件的格式化策略。內建型別提示將當地語系類別與型別名稱合併為一個標題，並保留說明。

開關預設啟用，可在使用者或工作區設定中切換。跨行宣告標頭與建構初始化清單使用一般換行，避免套用接續行的縮排。

VeroScript 檔案在索引標籤和檔案總管中提供簡潔的 V 圖示，支援淺色與深色佈景主題。是否顯示以及是否採用自訂圖示由目前的檔案圖示佈景主題決定；擴充功能不會切換你的佈景主題。

基本型別與 array 等內建容器統一使用精簡的型別標題。完成詳細資訊中的內建說明與中繼資料以說明文字顯示，實際宣告保留 VeroScript 程式碼區塊。原始碼別名、多載、連結與範例均保留。

反斜線續行的前置處理器指令及行註解內不顯示內建範本，結束後恢復正常補全。續行註解同時保留註解著色與一般 Enter 行為。

使用支援此功能的語言工具時，類別或結構中的補全可插入符合條件的繼承虛擬方法與介面成員實作；在空白插入位置也可使用對應的 refactor.rewrite 程式碼動作。外掛保留原生簽章、泛型型別替換、插入範圍及可編輯的程式碼片段方法本體；已實作、final 或無法存取的成員由語言伺服器篩選。

透過再匯出導覽至遞移相依性時，外掛保留實際目標，並開啟所屬伺服器提供的唯讀模組原始碼。

## 數值與變數編輯

使用支援此功能的 Runtime 或宿主時，VS Code 依各變數的 DAP `presentationHint.attributes` 顯示唯讀狀態，包括不可變 `variant` 的檢查子項、巢狀承載值及監看結果。外掛保留這些提示，不受工作階段是否支援變數編輯影響。寫入驗證由原生偵錯器負責；宿主未提供的唯讀提示不會由外掛推測。

`std::bigint`、`std::rational` 和 `std::numeric::rounding_mode` 等數值型別在語言服務結果中保留原生名稱。偵錯值保留原生顯示文字，不轉換為 JavaScript 數字。可用 API 以相符的 Runtime 及其標準程式庫為準。

## GUI 配套擴充套件

可選擇安裝 [VeroScript GUI 擴充套件](../../../../../VeroScriptGuiVSCode/Resources/Docs/User/zh-TW/index.md)，提供 `.vswml`／`.vswcss` 編輯及明確的原生檢查、編譯、預覽工作。它相依主擴充套件工具 API 1，本機版本須配套安裝。GUI Runtime 和提供者另行準備；`.vs`、LSP、DAP 仍由主擴充套件負責。

請完整保留解壓縮後的 Runtime，包括隨附的 `Vm/` 直譯器模組及其相依檔案。CLI、LSP、DAP 使用 Runtime 組裝的預設 VM；`run.backend: "vm"` 選擇的是執行策略。搬移或更新時一併處理相符的 Runtime 檔案，然後重新啟動語言伺服器。
