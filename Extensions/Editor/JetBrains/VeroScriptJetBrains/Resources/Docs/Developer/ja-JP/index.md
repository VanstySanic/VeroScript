# 開発者文書 — Rider

エディタとネイティブ間の共通担当範囲と六言語の保守は [共通エディタ統合](../../../../../../../../Resources/Docs/Developer/ja-JP/editors.md) で管理します。

`VeroScriptBundle` / `DynamicBundle` と各言語の `.properties` を使います。`MessageFormat` のプレースホルダーとアポストロフィーのエスケープを確認し、実行を許可された場合は実際の引数置換も検証します。

JDK/JVM 25、Gradle 9.5.0、Kotlin 2.4.0、IntelliJ Platform plugin 2.19.0 を使用します。SDK は Rider 2026.2.2 固定です。`sinceBuild=262.10315.191`、`strict-until-build=262.*` によりインストール対象は 262 ブランチに限定されます。他のブランチは別途検証が必要です。`VEROSCRIPT_TEST_RUNTIME` で現行ネイティブテストを有効にします。未指定は明示スキップです。任意の `VEROSCRIPT_TEST_JIT_BACKEND` は実モジュールテストを有効にします。SDK 構造と ZIP 確認は Rider UI 検証を代替しません。

```sh
./gradlew test verifyPluginProjectConfiguration verifyPluginStructure buildPlugin
./gradlew verifyPlugin
```

`gradlew.bat` (Windows) · `bash ./gradlew` (Linux) · `-PlocalIdePath=/absolute/path/to/Rider`

ネイティブ回帰テストは `std::memory` の名前空間・メンバー補完、ソース表記、ホバー、診断、同一バージョンのセマンティックトークン delta を対象とします。DAP テストはプラグインの LSP4J トランスポートで buffer、view、ウォッチを展開し、検査項目の変更拒否と、ステップ後のオブジェクト ID 保持および旧参照の失効を確認します。メタデータの数値はプロトコルの文字列として保持します。`variablesReference` は不透明なハンドルであり、メモリアドレスではありません。

子要素数がある場合は有界 DAP ページを要求し、短い応答で展開を終了します。件数がない場合は完全なスナップショットを一度だけ取得してローカルで分割します。100 件の応答だけではページング対応と判断できません。非同期応答とキャッシュ済みページのコールバックでは停止世代とノードの有効性を確認します。回帰テストは空一覧、99/100/101/250 件、短い応答、再開後の旧スナップショット、実 Runtime の 100 要素配列を対象とします。

デバッガーの自動ツールチップは、セッションが属するプロジェクトのエディターだけを追跡します。続行、ステップ、一時停止要求のエラーはその要求の世代にだけ適用され、古い世代の失敗は新しい停止に影響しません。現在の一時停止要求の失敗は接続を維持して報告し、通信切断は引き続き独立してセッションを終了します。プロトコルとポップアップのテスト用フィクスチャで、一時停止の失敗応答と停止通知の両方の到着順序を含む境界を検証します。

エクスポートされた別名の回帰テストでは、ソースのファサードを介した `export using` と `export typedef` の補完、非公開別名の除外、ホバー、定義への移動を確認します。CLI Run/Check は、同じ Runtime で構築した `.vslib` をファサードからインポートする場合も検証します。これらはネイティブのプロトコルとプロセスのテストであり、Rider UI の受け入れ確認を代替しません。

ローカルの字句解析はコアの `constexpr` キーワードに対応します。DAP 変数の `presentationHint.attributes` に `readOnly` が含まれる場合は変更操作を提供しません。他の表示属性は編集可否を変えず、ホストと実行ドメインの機能による制限も維持します。回帰用例はキーワードの境界と、読み取り専用、書き込み可能、他の表示属性を持つ子変数を対象とします。

## コンパイル拡張と生成ソース

DAP `stackTrace` のフレーム `column` は既に 1 始まりの UTF-16 列です。ローカルファイル、正の `sourceReference` の読み取り専用スナップショット、live domain に共通します。エディターの行テキストが利用できる場合、クライアントは 0 始まりへの変更と行範囲への制限だけを行い、サロゲートペアを分割しません。UTF-8 バイト列から再変換してはいけません。座標とコントローラーの回帰ケースは CJK、補助文字、CRLF を含みます。

最初と後続ページのスタックフレームを表示する前に、ソース参照を非同期で解決します。ローカルパスもある場合を含め、正の参照番号ごとに接続内で不変の読み取り専用ファイルをキャッシュします。スナップショットをプロジェクト操作と LSP から除外します。取得失敗時も停止を維持し、世代チェックで遅延した停止結果を除外し、破棄時にキャッシュを解放します。ネイティブ回帰はコンパイル拡張のインポート、生成された補完/ホバー/移動、生成本体へのステップイン、公開マクロのインポートを検証します。ネイティブレジストリと `ModuleEnvironment` はホスト API オプションであり LSP JSON 設定ではありません。`veroscript/moduleSource` はホストモジュール用です。プラグインは独立 LSP を起動し、ホスト LSP に接続しません。 失敗したソース要求はキャッシュから削除し、後のスタック読み込みで再試行できます。同じスタックページ内の重複参照は一度だけ取得します。

注釈名の照合は Tooling/Core が担当し、クライアントはソースの表記とサーバーのラベルを保持します。ネイティブ回帰テストは、再起動せずにカタログ定義の `caseSensitive` 方針を変更する場合、LSP/DAP の大文字小文字が混在するコンパイル注釈、`matches_name`/`case_sensitive` の補完、呼び出し可能型の引数ラベルを検証します。ドメインのプロトコル用フィクスチャでは、attach 応答前の停止イベント、能力情報の利用、およびその後の実行再開も検証します。

## エディター表示

生のエディターレクサーはプリプロセッサーに従い、バックスラッシュ直後の LF／CRLF だけを行コメントの継続として扱います。末尾の水平空白は除去しません。回帰テストは token の再開、切り詰め範囲、線形な文字読み取り数、GUI インラインの色分け、コメントや終了済み指令の後の空ブロック Enter を検証します。ネイティブ LSP の回帰は入れ子の呼び出し可能値、ジェネリック、別名、配列／map、暗黙のレシーバーと private メンバーの隠蔽を扱います。DAP の回帰は variant の検査・ウォッチ子要素の読み取り専用属性と、通常のローカル変数の編集可能性を検証します。

ドキュメントターゲットは公開 LSP トランスポートで非同期要求を行い、認識できる Markdown 見出しだけを調整してサーバーのシグネチャと説明を保持します。重複を避けるため、この記述子の標準ホバーターゲットを無効にします。文書の変更スタンプ、ファイルの有効性、クライアント状態で古い結果を破棄し、キャンセルを伝播します。IDE の Markdown レンダラーがテーマに従うコードブロックを描画します。デバッガーの値ポップアップは独立しています。 すべてのサーバー結果セクションで、ネイティブの型分類に付随する認識済みのローカライズされた組み込み型メタデータだけを統合し、ソースの型エイリアスとフェンス付きの例は内容を保持します。

Enter デリゲートは IDE コマンド内で一度だけ置換し、元に戻す操作とプロジェクトのインデントを保持します。字句解析でコメントと文字列を除外し、ディレクティブ、複数行ヘッダー、選択範囲、複数カーソル、現在行の後続部分を含め先頭 1 MiB を越える解析は通常の Enter に戻します。波括弧設定だけでは LSP を再起動しません。整形と診断はサーバーが担当します。テストは描画、非同期結果の失効、カーソル、元に戻す操作、関数の入力完了前後のネイティブ診断を検証します。Rider UI の受け入れ確認は別途必要です。

## コンテキスト設定

コンテキスト構成は保存済みローカルファイルだけを対象とし、継承したテンプレートを
Run/Check に整え、アタッチ専用項目を除去します。Check はスクリプト引数、入力、JIT
パスも除去し、適用可能な作業ディレクトリ・環境・コンパイラー設定は保持します。
構成検証では IDE のキャンセルをそのまま伝播し、構成エラーに包みません。

Check は常に `--backend=vm` を渡し、保存済みの Run バックエンド設定は変更しません。

<a id="rider-platform-sdk"></a>

`localIdePath` がない場合、両 Rider プロジェクトは `rider(platformVersion) { useInstaller = false }` で複数 OS 用 SDK アーカイブを解決します。プラットフォームのインストーラーを開発 SDK として使いません。`-PlocalIdePath=<directory>` は既存のローカル IDE を選択します。前述の Rider／ビルドブランチ、プラグイン依存と JDK 条件を維持し、各 OS を別途検証してください。
