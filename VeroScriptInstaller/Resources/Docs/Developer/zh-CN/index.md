# VeroScript 安装程序技术文档

`VeroScriptInstaller` 包含跨平台安装、修复、卸载、捆绑和包布局实现。本文面向维护者和发行工具作者。面向最终用户的命令请见[安装与分发指南](../../User/zh-CN/index.md)。

## 模块职责

模块分为四层：

- `Core/` 负责捆绑归档、清单、包元数据、验证、路径安全、平台信息、重试和安装引擎。
- `App/` 负责 Avalonia 图形应用、进度/报告和界面本地化。
- `Tool/` 负责命令行捆绑/构建入口。
- `Tests/` 验证核心、面向界面、捆绑和打包契约。

核心必须能在没有图形应用的情况下使用。界面文本、进度呈现和进程接线不得成为验证清单或执行安全文件系统操作的前提。

## 捆绑与清单不变量

捆绑归档、产品定义、包清单和安装程序清单必须在提取或替换前验证。路径必须相对于目标根目录验证；路径遍历、绝对路径逃逸、意外的外来内容和含义不明确的包条目都必须安全失败。可重试的文件系统操作不得将部分操作报告为成功。

在公共契约作出承诺时，安装、修复和卸载应具备幂等性。原子替换、清理、回滚行为和失败报告必须以核心实现和测试为依据。

## 平台集成

Windows 与 Unix 的路径集成是核心接口之后的独立实现。更新 `PATH`、shell 配置、权限和平台发现必须遵守各平台规则；不得把它们归并成不安全的字符串操作。

## 安装记录与回滚细节

安装按组件暂存，并写入安装记录；记录跟踪组件根目录、归属文件、产品标识、清单指纹及所有运行时 `PATH` 变更。修复要求安装程序包标识、产品版本、平台、架构和清单指纹与记录完全一致。卸载只移除已记录文件和归属的 `PATH` 条目，保留不属于安装程序的文件。

目标根目录不得与受保护的安装程序负载或彼此重叠；会检查受管目标及其祖先中的链接。迁移在暂存移动前验证现有记录、同级记录、目标安全性和所有权。提交前失败触发回滚；提交后清理失败会保留日志供后续清理尝试，且不会把已完成安装报告为失败。`LoadRecordAsync` 会在读取记录前执行事务恢复，包括 GUI 修复/卸载启动。

当前正式安装器收录功能组件，文档和示例通过 Resources 分发。旧清单与记录可能仍保留供修复／卸载使用的辅助组件；图形向导从新选择中排除它们，并拒绝依赖不可用组件的选择。记录实际安装的组件，不从当前源码树推断既有安装。

## 本地化与发行资源

本模块的界面本地化正本位于 `App/Resources/Localization/<culture>/`。安装器将这些 JSON 目录资源嵌入应用程序集。文化标签必须是带限定子标签的规范 BCP 47 标签。语言选择及英文回退由资源目录驱动。资源键、协议字段、枚举名、命令选项、路径、版本值和诊断 ID 均为技术标识符，须保留原拼写。
