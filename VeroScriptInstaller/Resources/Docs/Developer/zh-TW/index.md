# VeroScript Installer 技術文件

`VeroScriptInstaller` 實作跨平台安裝、修復、移除、封裝及套件配置。本文件面向維護者與發布工具開發者；使用者操作見[安裝與散發指南](../../User/zh-TW/index.md)。

## 模組職責

模組分為四層：

- `Core/` 管理封裝檔、資訊清單、套件中繼資料、驗證、路徑安全、平台資訊、重試及安裝引擎。
- `App/` 管理 Avalonia 圖形應用、進度、結果呈現及介面本地化。
- `Tool/` 提供封裝／建置的命令列入口。
- `Tests/` 驗證核心、介面邊界、封裝及打包契約。

核心必須在沒有圖形介面時仍可使用。驗證資訊清單或安全操作檔案，不得依賴介面文字、進度呈現或處理程序串接。

## 封裝與資訊清單不變條件

解開或替換前須驗證封裝、產品定義、套件資訊清單及安裝程式資訊清單。依預期根目錄檢查路徑，拒絕路徑穿越、絕對路徑逸出、非預期外來內容與不明確項目。重試不得把部分完成的操作誤報為成功。

在公開契約保證的範圍內，安裝、修復及移除應保持冪等。原子替換、清理、復原與失敗回報必須以核心實作及測試為依據。

## 平台整合

Windows 與 Unix 路徑整合是共用介面下的獨立實作。PATH 更新、shell 設定、權限與平台探索須保留各系統規則，不得簡化為不安全的單一字串操作。

## 安裝記錄與復原

安裝依元件暫存，並記錄元件根目錄、擁有檔案、產品身分、資訊清單指紋及執行時 `PATH` 變更。修復要求安裝套件身分、產品版本、平台、架構及指紋與記錄完全相符。移除僅刪除記錄中擁有的檔案與 PATH 項目，保留其他檔案。

目的根目錄不得與受保護的安裝程式內容或彼此重疊；管理路徑及祖先須檢查連結。移動前驗證既有記錄、相鄰記錄、目的安全與所有權。提交前失敗會復原；提交後清理失敗保留日誌供稍後重試，不把已完成安裝回報為失敗。`LoadRecordAsync` 讀取前先復原交易，圖形修復／移除的啟動也使用相同流程。

目前正式安裝器收錄功能元件，文件和範例透過 Resources 分發。舊清單與記錄可能仍保留供修復／解除安裝使用的輔助元件；圖形精靈從新選擇中排除它們，並拒絕相依於無法使用元件的選擇。記錄實際安裝的元件，不從目前原始碼樹推斷既有安裝。

## 本地化與散發資源

介面原始目錄由本模組的 `App/Resources/Localization/<culture>/` 管理，並以 JSON 嵌入應用程式組件。文化名稱使用帶限定資訊的正規 BCP 47 標籤；選擇與英文回退依目錄決定。資源鍵、協定欄位、列舉名稱、命令選項、路徑、版本及診斷 ID 保留原拼寫。
