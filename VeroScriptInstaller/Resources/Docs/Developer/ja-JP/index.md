# VeroScript Installer 技術文書

`VeroScriptInstaller` は各プラットフォームのインストール、修復、アンインストール、バンドル、パッケージ構成を実装します。このページは保守担当者と公開ツールの開発者向けです。利用者の操作は [インストールと配布ガイド](../../User/ja-JP/index.md) を参照してください。

## モジュールの責務

モジュールは次の 4 層で構成します。

- `Core/` はバンドル、マニフェスト、パッケージメタデータ、検証、パス安全性、環境情報、再試行、インストール処理を管理します。
- `App/` は Avalonia の画面、進捗、結果表示と UI のローカライズを管理します。
- `Tool/` はバンドル作成とビルドのコマンド入口を提供します。
- `Tests/` は中核処理、UI 境界、バンドル、パッケージ化の契約を検証します。

中核処理は GUI がなくても利用できる必要があります。マニフェスト検証や安全なファイル操作を、画面の文字列、進捗表示、プロセス連携に依存させません。

## バンドルとマニフェストの不変条件

展開や置換の前にバンドル、製品定義、パッケージ／インストーラーマニフェストを検証します。パスは想定ルートを基準に調べ、トラバーサル、絶対パスによる逸脱、想定外の他者の内容、曖昧なエントリーを拒否します。再試行によって途中状態を成功扱いしてはいけません。

公開契約で保証する範囲ではインストール、修復、削除を冪等にします。アトミック置換、後始末、ロールバック、失敗通知は実装とテストに基づいて記述します。

## プラットフォームとの統合

Windows と Unix のパス統合は共通インターフェース配下の別実装です。PATH、シェル設定、権限、環境検出には各 OS の規則を保持し、安全でない単一文字列処理へまとめません。

## インストール記録とロールバック

インストールはコンポーネント単位で準備し、ルート、所有ファイル、製品識別、マニフェスト指紋、実行時 `PATH` 変更を記録します。修復には記録と完全に一致するインストーラーパッケージ識別、製品版、OS、アーキテクチャー、指紋が必要です。削除対象は所有するファイルと PATH エントリーだけで、それ以外は残します。

保存先は保護されたインストーラー内容や他の保存先と重ねません。管理対象パスと祖先のリンクを検査します。移設前に既存記録、隣接記録、保存先の安全性と所有権を確認します。コミット前の失敗はロールバックし、コミット後の後始末失敗はジャーナルを残して再試行できるようにし、完了済みインストールを失敗扱いしません。`LoadRecordAsync` は記録を読む前にトランザクションを復旧し、GUI 修復／削除の起動も同じ経路を使います。

現在の正式インストーラーは機能コンポーネントを含み、文書とサンプルは Resources で配布します。旧マニフェストや記録には修復・削除用の補助コンポーネントが残る場合がありますが、GUI ウィザードは新規選択から除外し、利用できない依存物を要する選択を拒否します。現行ソースから推測せず、実際に導入したコンポーネントを記録します。

## ローカライズと配布リソース

UI の元カタログは `App/Resources/Localization/<culture>/` に置き、JSON としてアプリケーションアセンブリーへ埋め込みます。カルチャー名は修飾された正規 BCP 47 タグを使います。言語選択と英語フォールバックはカタログに従います。リソースキー、プロトコルフィールド、列挙名、オプション、パス、版、診断 ID は表記を維持します。
