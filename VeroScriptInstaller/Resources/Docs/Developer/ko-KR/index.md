# VeroScript Installer 기술 문서

`VeroScriptInstaller`는 플랫폼별 설치, 복구, 제거, 번들 및 패키지 구성을 구현합니다. 이 문서는 유지 관리자와 배포 도구 개발자를 위한 것입니다. 사용자 명령은 [설치 및 배포 가이드](../../User/ko-KR/index.md)를 참고하세요.

## 모듈 책임

모듈은 네 계층으로 나뉩니다.

- `Core/`는 번들, 매니페스트, 패키지 메타데이터, 검증, 경로 안전, 플랫폼 정보, 재시도 및 설치 엔진을 담당합니다.
- `App/`은 Avalonia 화면, 진행 상황, 결과 표시 및 UI 현지화를 담당합니다.
- `Tool/`은 번들 생성과 빌드의 명령줄 진입점을 제공합니다.
- `Tests/`는 핵심 처리, UI 경계, 번들 및 패키징 계약을 검증합니다.

핵심 처리는 GUI 없이 사용할 수 있어야 합니다. 매니페스트 검증과 안전한 파일 작업에 화면 문자열, 진행 표시, 프로세스 연결이 필수여서는 안 됩니다.

## 번들과 매니페스트 불변 조건

압축 해제나 교체 전에 번들, 제품 정의, 패키지/설치 매니페스트를 검증합니다. 의도한 루트를 기준으로 경로를 검사하고 경로 이탈, 절대 경로 탈출, 예상치 못한 외부 콘텐츠 및 모호한 항목은 거부합니다. 재시도 때문에 일부만 완료된 작업을 성공으로 보고해서는 안 됩니다.

공개 계약이 보장하는 범위에서 설치, 복구, 제거는 멱등적이어야 합니다. 원자적 교체, 정리, 롤백 및 실패 보고는 핵심 구현과 테스트를 근거로 문서화합니다.

## 플랫폼 통합

Windows와 Unix 경로 통합은 공통 인터페이스 아래 별도 구현입니다. PATH 변경, 셸 설정, 권한, 플랫폼 탐지는 각 시스템 규칙을 유지하며 안전하지 않은 단일 문자열 처리로 합치지 않습니다.

## 설치 기록 및 롤백

설치는 구성 요소별로 준비하고 루트, 소유 파일, 제품 식별자, 매니페스트 지문 및 실행 시 `PATH` 변경을 기록합니다. 복구는 기록과 정확히 일치하는 설치 패키지 식별자, 제품 버전, 플랫폼, 아키텍처, 지문을 요구합니다. 제거는 소유한 파일과 PATH 항목만 지우고 다른 파일은 보존합니다.

대상 루트는 보호된 설치 프로그램 콘텐츠 또는 서로와 겹치면 안 됩니다. 관리 경로와 상위 경로의 링크를 검사합니다. 이동 전 기존 기록, 인접 기록, 대상 안전성 및 소유권을 확인합니다. 커밋 전 실패는 롤백하고 커밋 후 정리 실패는 나중에 재시도하도록 저널을 유지하며 완료된 설치를 실패로 보고하지 않습니다. `LoadRecordAsync`는 기록을 읽기 전 트랜잭션을 복구하며 GUI 복구/제거 시작도 같은 경로를 사용합니다.

현재 정식 설치 패키지는 기능 구성 요소를 포함하며 문서와 예제는 Resources로 배포합니다. 이전 매니페스트와 기록에는 복구/제거용 보조 구성 요소가 남을 수 있지만 GUI 마법사는 새 선택에서 제외하고 사용할 수 없는 구성 요소에 의존하는 선택을 거부합니다. 현재 소스에서 추론하지 말고 실제 설치한 구성 요소를 기록합니다.

## 현지화 및 배포 리소스

UI 원본 카탈로그는 `App/Resources/Localization/<culture>/`에 있으며 JSON으로 앱 어셈블리에 포함합니다. 문화권 이름은 정규화된 한정 BCP 47 태그를 사용합니다. 언어 선택과 영어 대체는 카탈로그를 따릅니다. 리소스 키, 프로토콜 필드, 열거형 이름, 옵션, 경로, 버전 및 진단 ID는 철자를 유지합니다.
